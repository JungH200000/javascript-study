# 사용할 API

학습에는 `Color Survey API`를, 실습에는 `Avatar API`를 사용할 것입니다.

- [Color Survey API Document](https://www.codeit.kr/tutorials/36/color-survey-api-documentation)

  - `Color Survey API`는 사용자가 제출한 MBTI와 선호 색상 데이터를 저장합니다.

- [Avatar API Document](https://www.codeit.kr/tutorials/74/avatar-api-documentation)

  - `Avatar API`는 사용자가 제출한 아바타 정보를 저장합니다. `hairType`, `hairColor` 등의 정보를 이용해서 나만의 아바타를 만드는 데 사용됩니다.
