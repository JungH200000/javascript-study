# 문장과 표현식 (Statements & Expressions)

> **핵심 정의 요약**
>
> - **문장(Statement)**: _어떤 동작을 수행하는_ 최소 코드 단위.
> - **표현식(Expression)**: _평가하면 하나의 값이 되는_ 모든 코드.

---

## 문장 (Statements)

문장은 **동작을 일으키는 코드**다. 선언, 할당, 조건, 반복 등이 여기에 해당한다.

```js
let x; // 변수 "선언" 동작 → 문장
x = 3; // 값 "할당" 동작 → 문장

if (x < 5) {
  // 조건을 평가해 분기 "실행" → 문장
  console.log('x는 5보다 작다.');
} else {
  console.log('x는 5보다 같거나 크다.');
}

for (let i = 0; i < 5; i++) {
  // 반복 "실행" → 문장
  console.log(i);
}
```

- **포인트**: ‘~문’(선언문, 할당문, 조건문, 반복문)은 **동작**을 수행한다.

---

## 표현식 (Expressions)

표현식은 **결과적으로 값이 되는 코드**다. 길이와 형태와 무관하게 **평가 결과가 값**이면 표현식이다.

```js
5; // 값 그 자체 → 표현식 (결과: 5)
('string'); // 괄호로 감싸도 값 → 표현식 (결과: 'string')
```

연산을 통해 **새 값을 만들어도** 표현식이다.

```js
5 + 7; // 12
'I' + ' Love ' + 'You'; // 'I Love You'
true && null; // null (왼쪽이 truthy라 오른쪽 값을 반환)
```

식별자/프로퍼티 접근 역시 **값으로 평가**된다.

```js
const title = 'JavaScript';
const Java = { name: 'Java' };
const number = [1, 2, 3];

typeof Java; // 'object'
title; // 'JavaScript'
Java.name; // 'Java'
number[5]; // undefined
```

---

## 표현식이면서 문장, 문장이면서 표현식

일부 코드는 **동작을 하면서 동시에 값**이기도 하다.

- **할당식**: 값을 할당하는 **동작 + 그 값을 반환**.

  ```js
  title = 'JavaScript'; // 표현식(결과: 'JavaScript')이면서 문장(할당 동작)
  ```

- **함수 호출**: 함수를 실행하는 **동작 + 반환값**을 가진 표현식.

  ```js
  function sayHello() {
    return 'Hi';
  }
  sayHello(); // 표현식(결과: 'Hi')이면서 문장(호출 동작)
  ```

- `console.log` 호출은 **undefined를 반환**한다.

  ```js
  console.log('Java'); // 동작은 출력, 값은 undefined
  ```

## 표현식인 문장 vs 표현식이 아닌 문장

- **구분 요령**: 해당 코드를 **변수에 할당**하거나 **함수 인자**로 넣어보자.
  가능하면 **표현식인 문장**, 불가능하면 **표현식이 아닌 문장**이다.

```js
let x;
x = 3;

// 표현식이 아닌 문장을 인자로 넣으려 하면 SyntaxError
console.log(if (x < 5) {
  console.log('x는 5보다 작다');
} else {
  console.log('x는 5보다 크다');
});
// Uncaught SyntaxError: Unexpected token 'if'

const someloop = for (let i = 0; i < 5; i++) {
  console.log(i);
};
// Uncaught SyntaxError: Unexpected token 'for'
```

- **포인트**

  - `if`, `for` 같은 **조건문/반복문**은 **값으로 평가되지 않음** → **표현식이 아닌 문장**.
  - 할당식·함수호출처럼 **값을 가지는 문장**은 **표현식인 문장**.

---

## 세미콜론과 중괄호로 범위 보기

- 일반적으로 **표현식인 문장**은 `;`로 끝나고,
  **표현식이 아닌 문장**은 **중괄호 `{}`** 로 코드 블록 범위를 드러낸다.

```js
let x;
x = 3; // ; 로 끝나는 표현식인 문장

for (let i = 0; i < 5; i++) {
  // 블록 {} 로 범위가 보이는 표현식이 아닌 문장
  console.log(i);
}
```

---

## 핵심 요약

- **문장**은 동작을 수행하고, **표현식**은 값으로 평가된다.
- 할당식·함수호출처럼 **값을 가지는 문장**은 “**표현식인 문장**”이 될 수 있다.
- `if`, `for` 등은 **값이 아닌 문장**이므로 변수 할당/함수 인자로 사용할 수 없다.
- 대체로 **`;`는 표현식인 문장**, **`{}`는 표현식이 아닌 문장**의 범위를 나타낸다.
