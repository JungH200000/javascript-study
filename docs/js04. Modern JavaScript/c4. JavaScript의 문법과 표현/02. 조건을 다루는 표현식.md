# 조건을 다루는 표현식 — 조건(삼항) 연산자

> **한 줄 요약** > **조건 연산자**는 `조건 ? 값1 : 값2` 형태로 **조건에 따라 값을 고르는 표현식**이다.

---

## 배경: 기존의 조건 처리 (문장)

JavaScript에서 조건을 다루는 전통적인 방법은 **if 문**과 **switch 문** 같은 **문장**을 쓰는 것이다.

```js
if (조건) {
  // 조건이 true일 때 동작
} else {
  // 조건이 false일 때 동작
}

switch (값) {
  case A:
    // 값이 A와 일치할 때 동작
    break;
  default:
  // 값이 일치하는 case가 없을 때 동작
}
```

- 키워드 뒤 `()`에 **조건**을 두고, **코드 블록**에서 동작을 기술한다.

---

## 조건 연산자(Conditional / Ternary Operator)

- **정의**: `조건 ? (truthy일 때 값/표현식) : (falsy일 때 값/표현식)`
- `?`와 `:` **두 기호**를 사용하며, **피연산자가 3개**라서 _삼항(ternary)_ 연산자라고 부른다.
- **if 문과의 대응**

  - `if (조건)` ↔ `조건`
  - `then 블록` ↔ `? 뒤 표현식`
  - `else 블록` ↔ `: 뒤 표현식`

---

## 예시: 합격/불합격 판별 (표현식으로 값 선택)

```js
const CUT_OFF = 80;

function passChecker(score) {
  return score > CUT_OFF ? '합격!' : '불합격!';
}

console.log(passChecker(90)); // 합격!
```

- `score > CUT_OFF`가 **truthy**면 `'합격!'`, 아니면 `'불합격!'`을 **반환**한다.
- 같은 로직을 **if 문**으로 작성하면 다음과 같다.

```js
const CUT_OFF = 80;

function passChecker(score) {
  // return score > CUT_OFF ? '합격!' : '불합격!';
  if (score > CUT_OFF) {
    return '합격!';
  } else {
    return '불합격!';
  }
}

console.log(passChecker(70)); // 불합격!
```

- **차이점**: 조건 연산자는 **값을 만드는 “표현식”** 이라 더 **간결**하게 “조건에 따른 값 선택”을 표현할 수 있다.

---

## 조건 연산자의 한계: 문장 동작은 못 한다

조건 연산자는 **표현식**이므로, **변수 선언/반복 같은 문장 동작**은 넣을 수 없다. 이런 동작이 필요하면 **if 문**을 사용해야 한다.

```js
const CUT_OFF = 80;

function passChecker(score) {
  // return score > CUT_OFF ? '합격!' : '불합격!';
  if (score > CUT_OFF) {
    const msg = '합격!'; // ✅ 변수 선언(문장)
    return msg;
  } else {
    for (let i = 0; i < 3; i++) {
      // ✅ 반복(문장)
      console.log(i);
    }
    return '불합격!';
  }
}

console.log(passChecker(70));
```

- **정리**: 조건 연산자는 **값 선택**에, if 문은 **동작 제어**에 적합하다. 따라서 **모든 if 문을 대체할 수는 없다**.

---

## 핵심 요약

- **조건 연산자 `?:`** 는 **조건에 따라 값을 반환하는 표현식**이다.
- **if 문**은 **동작(문장)**, **조건 연산자**는 **값(표현식)** 에 강하다.
- 간단한 “값 선택”은 **삼항 연산자**가 더 **간결**하다.
- **변수 선언/반복** 등 문장 동작이 필요하면 **if 문**을 쓴다.
- (오개념 정정) `?:`는 **ES2015 이전부터 존재**했다.
