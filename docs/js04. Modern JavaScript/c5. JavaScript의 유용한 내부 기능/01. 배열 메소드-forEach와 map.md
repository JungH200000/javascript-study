# 배열 메소드: forEach와 map

배열 요소를 **순서대로 순회**하며 작업할 때, `for...of` 외에도 배열 전용 메소드인 **`forEach`** 와 **`map`** 을 사용할 수 있다.
두 메소드는 **콜백 함수를 요소마다 실행**한다는 공통점이 있지만, **반환값과 사용 목적**이 다르다.

---

## 0) 먼저: for...of 예시 (비교용)

```js
const members = ['청아', '지원', '세경', '현정'];

for (let member of members) {
  console.log(`${member}님이 입장하셨습니다.`);
}
```

- `for...of`는 **요소를 하나씩 꺼내며** 반복한다.
- 아래의 `forEach`/`map`은 **배열 메소드**로, 같은 순회 작업을 **콜백 함수**로 처리한다.

---

## 1) forEach

> **정의:** 각 요소에 대해 콜백을 실행하고 **아무 것도 반환하지 않는다**(반환값 `undefined`).
> **한 줄 요약:** **부수 효과(출력, 변경 등)** 를 위해 쓰는 순회.

### (1) 기본 사용

```js
const members = ['청아', '지원', '세경', '현정'];

members.forEach(function (member) {
  console.log(`${member}님이 입장하셨습니다.`);
});
```

- 콜백의 **첫 번째 매개변수**는 **요소 값**이다. (필요 시 `index`, `array`도 받을 수 있다)
- 아래처럼 `for...of`와 **역할 대응**이 된다.

```js
for (let member of members) {
  /* ... */
}

members.forEach(function (member) {
  /* ... */
});
```

### (2) 화살표 함수로 쓰기

```js
const members = ['청아', '지원', '세경', '현정'];

members.forEach((member) => {
  console.log(`${member}님이 입장하셨습니다.`);
});
// members.forEach((member) => console.log(`${member}님이 입장하셨습니다.`));
```

### (3) 콜백 매개변수: (element, index, array)

```js
const members = ['청아', '지원', '세경', '현정'];

members.forEach((member, i) => {
  console.log(`${i} ${member}님이 입장하셨습니다.`);
});
// 0 청아님이 입장하셨습니다.
// 1 지원님이 입장하셨습니다.
// 2 세경님이 입장하셨습니다.
// 3 현정님이 입장하셨습니다.
```

- `index`를 활용하면 **다른 배열과 같은 인덱스**로 매칭할 수 있다.

```js
const firstName = ['청아', '지원', '세경', '현정'];
const lastName = ['강', '이', '하', '신'];

firstName.forEach((firstName, i) => {
  console.log(`${lastName[i]}${firstName}님이 입장하셨습니다.`);
});
```

- 세 번째 인자인 **배열 자체(`array`/`arr`)** 도 받을 수 있다.

```js
const firstName = ['청아', '지원', '세경', '현정'];
const lastName = ['강', '이', '하', '신'];

firstName.forEach((firstName, i, arr) => {
  console.log(`${lastName[i]}${firstName}님이 입장하셨습니다.`);
  console.log(arr); // forEach를 호출한 그 배열
});
```

> 참고: 보통은 외부 변수로 배열을 참조하므로 세 번째 인자는 자주 쓰이지 않는다.

---

## 2) map

> **정의:** 각 요소에 대해 콜백을 실행하고, **콜백의 반환값들로 구성된 ‘새로운 배열’을 반환**한다.
> **한 줄 요약:** **입력 배열 → 변환 → 새 배열**이 필요할 때 사용.

### (1) 동작 방식은 forEach와 유사

```js
const firstName = ['청아', '지원', '세경', '현정'];
const lastName = ['강', '이', '하', '신'];

firstName.map((firstName, i, arr) => {
  console.log(`${lastName[i]}${firstName}님이 입장하셨습니다.`);
  console.log(arr);
});
```

### (2) 반환값으로 새 배열 만들기

```js
const firstName = ['청아', '지원', '세경', '현정'];
const lastName = ['강', '이', '하', '신'];

firstName.map((firstName, i) => {
  return lastName[i] + firstName;
});
```

- 콜백에서 `return`한 값들이 **새 배열**의 요소가 된다.

```js
// ...
const fullNames = firstName.map((firstName, i) => {
  return lastName[i] + firstName;
});

console.log(fullNames); // (4) ['강청아', '이지원', '하세경', '신현정']
```

- 화살표 함수로 더 간단히:

```js
// ...
const fullNames = firstName.map((firstName, i) => lastName[i] + firstName);
```

### (3) forEach는 반환값이 없다

```js
const firstName = ['청아', '지원', '세경', '현정'];
const lastName = ['강', '이', '하', '신'];

const fullNames = firstName.forEach((firstName, i) => lastName[i] + firstName);

console.log(fullNames); // undefined
```

- **새 배열이 필요하면 `map`**,
  **단순 반복(출력/수정 등)이라면 `forEach`** 를 사용한다.

---

## 3) 반복 중 배열 수정 시 주의

- `forEach`/`map` 모두, **실행 시점의 배열 길이**를 기준으로 **최대 반복 횟수**가 정해진다.

### (1) 길이를 늘리면: 추가 요소는 순회 대상이 아님

```js
const members = ['청아', '지원', '세경', '현정'];

members.forEach((member) => {
  console.log(`${member}님이 입장하셨습니다.`);
  members.push('하경'); // 배열 끝에 새로운 요소 추가하고, 추가된 뒤의 배열의 길이를 반환
});

console.log(members);
// 청아님이 입장하셨습니다.
// 지원님이 입장하셨습니다。
// 세경님이 입장하셨습니다。
// 현정님이 입장하셨습니다。
// (8) ['청아', '지원', '세경', '현정', '하경', '하경', '하경', '하경']
```

- 순회는 **처음 길이(4)** 만큼만 실행되고 끝난다. (무한 루프 아님)

### (2) 길이를 줄이면: 반복 횟수도 줄어든다

```js
const members = ['청아', '지원', '세경', '현정'];

members.forEach((member) => {
  console.log(`${member}님이 입장하셨습니다.`);
  members.pop(); // 배열의 마지막 요소를 제거하고, 그 제거된 요소를 반환
});

console.log(members);
// 청아님이 입장하셨습니다.
// 지원님이 입장하셨습니다.
// (2) ['청아', '지원']
```

- 순회 중에 요소가 제거되면 **남은 반복도 함께 줄어든다**.

---

## 4) 핵심 정리 표

| 구분      | 목적                         | 콜백 반환값 사용 | 최종 반환값        |
| --------- | ---------------------------- | ---------------- | ------------------ |
| `forEach` | **부수 효과**(로그/수정 등)  | 사용 안 함       | `undefined`        |
| `map`     | **변환 결과 새 배열** 만들기 | **사용함**       | **새 배열(Array)** |

---

## 핵심 요약

- `forEach`: 요소마다 콜백을 실행하지만 **새 배열을 만들지 않음**(반환 `undefined`).
- `map`: 요소마다 콜백의 **반환값들로 새 배열을 생성**.
- 콜백 매개변수는 `(요소, index, array)` 순서로 받을 수 있다.
- 순회 중 배열을 수정하면, **처음 길이만큼만 순회**하며, **길이를 줄이면 반복도 줄어든다**.
- **새 배열이 필요하면 `map`**, **그 외 단순 반복은 `forEach`** 를 사용한다.
