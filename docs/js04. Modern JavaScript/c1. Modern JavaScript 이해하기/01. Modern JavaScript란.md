# Modern JavaScript란?

JavaScript를 배우다 보면 종종 **ECMAScript**라는 용어를 접한다.  
Modern JavaScript는 이 ECMAScript 표준을 바탕으로, 현시점에서 널리 사용되는 최신 문법을 따르는 JavaScript를 의미한다.

---

## ECMAScript란?

**정의:** ECMAScript는 JavaScript의 **표준 명세(스펙)** 를 뜻한다.  
즉, JavaScript를 어떤 규칙에 따라 구현해야 하는지를 문서로 정리한 것이다.

- JavaScript도 다른 언어처럼 계속 발전한다.
- 새로운 기능이 추가되고 기존의 불편한 점이 개선될 때마다, 이를 공식적으로 규정한 문서가 **ECMA-262**이며, 이 문서가 바로 **ECMAScript**다.
- 이 표준은 국제 표준화 기구 **Ecma International**에서 관리한다.

---

## ECMAScript 버전의 발전

- ECMAScript는 1997년에 처음 등장했다.
- 초기에는 **ES1, ES2, ES3 …** 이런 식으로 버전을 표시했다.
- **ES6(2015)** 부터는 **연도 기반 명칭**을 사용한다.  
  예: **ES2015(=ES6)**, **ES2016(=ES7)**, ...

👉 따라서 ES6는 `ES6` 또는 `ES2015` 두 가지 방식으로 불린다.

---

## ES6(ES2015)의 의미

**한 줄 요약:** ES6는 JavaScript 발전의 전환점이다.

- ES5까지의 문제점을 보완하고, 더 **안전하고 간결한 코드 작성**이 가능하도록 많은 기능이 추가되었다.
- 그 영향력이 커서, **ES6 이전**과 **ES6 이후**를 구분하기 위해 **ES6+** 라는 표현까지 생겼다.

---

## 브라우저 호환성 문제

문제는 표준이 곧바로 **모든 브라우저에서 지원되지 않는다**는 점이다.

- 새로운 기능이 추가되어도, 브라우저가 이를 즉시 반영하지 못한다.
- 따라서 개발자는 최신 표준을 무조건 사용하는 것이 아니라,  
  **주요 브라우저가 지원하는 범위 내에서** 표준을 적용하는 방식이 일반적이다.

---

## Modern JavaScript란?

- **현시점에서 널리 지원되는 ECMAScript 표준을 따르는 JavaScript**
- 즉, "최신이면서도 실무에서 쓸 수 있는" JavaScript를 말한다.

앞으로 Modern JavaScript 학습에서는:

1. **기본 개념**을 다시 견고히 다지고,
2. **새롭게 추가된 문법 중 실용적인 것들**을 익히고,
3. JavaScript를 기반으로 한 여러 기술을 다루기 위한 **필수 지식**을 함께 정리한다.

---

## 핵심 요약

- **ECMAScript = JavaScript 표준 명세(ECMA-262 문서)**
- **버전 체계:** ES1~ES5 → ES6(2015) 이후 연도 표기
- **ES6(2015):** JavaScript 발전의 전환점, 다양한 개선된 문법 도입
- **브라우저 호환성:** 최신 기능을 바로 적용하기 어렵기 때문에 지원 범위를 고려해야 함
- **Modern JavaScript:** 현시점에서 실무적으로 사용할 수 있는 최신 ECMAScript 기반의 JavaScript
