# JavaScript와 ECMAScript

JavaScript를 배우다 보면 **ECMAScript**라는 용어를 접하게 된다.  
두 용어는 종종 혼동되지만, 실제로는 명확한 차이가 있다.

---

## 1. 공식 문서

**정의:** ECMAScript는 JavaScript의 **표준 명세(스펙)** 다.  
즉, JavaScript가 따라야 하는 규칙과 기능이 정리된 문서다.

- 공식 문서: [ECMA-262 (ECMA International)](https://ecma-international.org/publications-and-standards/standards/ecma-262/)

---

## 2. 브라우저 지원 현황

ECMAScript는 매년 새로운 문법이 추가되지만,  
브라우저가 이를 **바로 지원하지는 않는다.**

- [호환성 테이블](https://compat-table.github.io/compat-table/es6/)
- [문법 검색으로 확인하는 호환성 테이블](https://caniuse.com/)

👉 개발할 때는 **최신 표준 문법**이라도, 실제 브라우저 지원 여부를 확인하는 것이 중요하다.

---

## 3. 버전의 정식 표기

- **ES6(2015)** 부터는 연도 기반 명칭을 사용한다.
  - 예: **ECMAScript 2015 (ES6)**, **ECMAScript 2016 (ES7)**
- 개발자들 사이에서는 **ES6, ES7**처럼 숫자만 쓰기도 하지만,  
  공식 표기는 반드시 연도를 붙여 **ECMAScript 20XX** 형태로 발표된다.

---

## 4. JavaScript vs ECMAScript

두 용어는 비슷해 보이지만, 본질적으로 다르다.

### (1) 언어 vs 표준

- **JavaScript:** 실제 프로그래밍 언어
- **ECMAScript:** 언어가 따라야 하는 표준 (일종의 **설명서**)

👉 쉽게 말해:

- ECMAScript = "설명서"
- JavaScript = "설명서를 기반으로 만든 결과물"

### (2) ECMAScript 준수 언어들

- JavaScript는 ECMAScript를 따르는 대표적인 언어다.
- 하지만 JavaScript 외에도 **JScript(마이크로소프트)**, **ActionScript(어도비 플래시)** 등 다른 언어들도 ECMAScript를 준수한다.

### (3) 추가 기능

- JavaScript는 ECMAScript에 정의된 기능 **+ 부가 기능**을 가진다.
- 특히 HTML과 상호작용하는 **DOM(Document Object Model)** 관련 문법은 ECMAScript 표준이 아니라, **WebIDL**이라는 별도의 표준에 의해 정의된다.

---

## 핵심 요약

- **ECMAScript = JavaScript 표준 명세(ECMA-262 문서)**
- **브라우저 지원:** 최신 문법이 추가되더라도, 실제 브라우저 호환성을 반드시 확인해야 함
- **버전 표기:** ES6부터는 연도 표기(ECMAScript 2015 등)가 정식
- **차이점:** ECMAScript는 "표준", JavaScript는 이를 기반으로 만들어진 "언어"이며, DOM 같은 기능은 ECMAScript 외부 표준(WebIDL)에 속한다
