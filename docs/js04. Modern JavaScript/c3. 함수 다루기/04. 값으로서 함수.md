# 📘 값으로서 함수

JavaScript에서는 **함수를 특별한 종류의 값**으로 취급합니다. 이 때문에 함수를 변수에 담거나, 다른 함수에 전달하거나, 반환값으로 돌려줄 수 있습니다. 이런 특성은 JavaScript가 **일급 함수(First-Class Function)** 를 지원한다는 의미입니다.

---

## 1. 함수도 값이다

```js
const printJS = function () {
  console.log('JavaScript!');
};
```

위 코드는 **함수 표현식**을 사용하여 함수를 값처럼 변수에 담은 예시입니다.
`typeof` 연산자로 함수의 타입을 확인해 보면 `"function"`이 출력되지만, 실제로는 **객체(Object)** 의 한 형태로 취급됩니다.

```js
console.log(typeof printJS); // function
```

---

## 2. console.dir()로 살펴보기

```js
const printJS = function () {
  console.log('JavaScript!');
};

console.dir(31);
console.dir('JavaScript');
console.dir(true);
console.dir(null);
console.dir(undefined);
console.dir({});
console.dir([]);
console.dir(printJS);
```

### 실행 결과 (브라우저 콘솔 예시)

```
31
JavaScript
true
null
undefined
Object
Array(0)
ƒ printJS()
```

함수는 다른 기본형과 달리 **객체처럼 속성을 가진 모습**으로 출력됩니다.

펼쳐보면 함수 객체는 여러 프로퍼티를 갖습니다:

```
ƒ printJS()
  length: 0
  name: "printJS"
  prototype: {}
  arguments: null
  caller: null
  [[FunctionLocation]]: study.js:1
  [[Prototype]]: ƒ ()
  [[Scopes]]: Scopes[2]
```

즉, 함수는 호출 가능한 객체라는 점이 특징입니다.

---

## 3. 다양한 활용 방식

### (1) 일반 호출

```js
const printJS = function () {
  console.log('JavaScript!');
};

printJS(); // JavaScript!
```

### (2) 객체의 메서드로 사용

```js
const myObject = {
  brand: 'JS',
  bornYear: 2000,
  isVeryNice: true,
  sayHello: function (name) {
    console.log(`Hi! ${name}`);
  },
};

myObject.sayHello('JavaScript');
// Hi! JavaScript
```

객체의 프로퍼티에 함수를 담으면, 그 함수는 **메서드**로 동작합니다.

---

### (3) 배열 요소로 사용

```js
const myArray = [
  'JavaScript',
  2000,
  true,
  function (name) {
    console.log(`Hi!, ${name}`);
  },
];

myArray[3]('JavaScript');
// Hi!, JavaScript
```

배열의 요소로 함수를 넣어두고, 배열 인덱스로 접근해 실행할 수도 있습니다.

---

### (4) 콜백 함수로 전달

```js
const myBtn = document.querySelector('#myBtn');

myBtn.addEventListener('click', function () {
  console.log('button is clicked!');
});
```

이벤트가 발생했을 때 실행할 코드를 **함수 형태로 전달**합니다. 이렇게 다른 함수의 **파라미터로 전달되는 함수**를 **콜백 함수(Callback Function)** 라고 합니다.

---

### (5) 함수 반환값으로 활용 (고차 함수)

```js
function getPrintHi() {
  return function () {
    console.log('Hi');
  };
}

const sayHi = getPrintHi();
sayHi(); // Hi
```

여기서 `getPrintHi`는 함수를 반환하는 함수로, 이런 함수를 **고차 함수(Higher-Order Function)** 라고 합니다.
특별한 경우에는 반환된 함수를 바로 실행할 수도 있습니다:

```js
getPrintHi()(); // Hi
```

---

## ✅ 핵심 요약

- JavaScript에서 **함수는 값으로 취급**된다. (객체의 한 형태)
- 따라서 변수에 담기, 객체 프로퍼티나 배열 요소로 사용, 다른 함수의 인자로 전달, 반환값으로 리턴 등이 모두 가능하다.
- 이렇게 함수를 값처럼 다룰 수 있는 특성을 **일급 함수(First-Class Function)** 라고 한다.
- 이 덕분에 JavaScript는 콜백 함수, 고차 함수 같은 다양한 프로그래밍 패턴을 지원한다.
