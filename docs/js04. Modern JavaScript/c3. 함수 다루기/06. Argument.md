# Argument

> **정의 한 줄 요약**: **파라미터(Parameter)** 는 *함수 선언부*의 자리표시자이고, **아규먼트(Argument)** 는 _함수 호출 시_ 파라미터로 **전달되는 실제 값**이다.

---

## 1) 파라미터와 아규먼트 기본

```js
function printArgument(a, b, c) {
  console.log(a);
  console.log(b);
  console.log(c);
}

printArgument('Ha', 'Chung', 'Ah');
// Ha
// Chung
// Ah
```

- `a, b, c`는 **파라미터**.
- 호출 시 전달한 `'Ha'`, `'Chung'`, `'Ah'`는 **아규먼트**다.

아규먼트 개수에 따라 동작을 확인해 보자.

```js
function printArgument(a, b, c) {
  console.log(a);
  console.log(b);
  console.log(c);
  console.log('--------------------');
}

printArgument('Ha', 'Chung', 'Ah');
// Ha
// Chung
// Ah
// --------------------

printArgument('JavaScript');
// JavaScript
// undefined
// undefined
// --------------------

printArgument('Ha', 'Ah');
// Ha
// Ah
// undefined
// --------------------

printArgument('Jav', 'Hyun', 'Chung', 'Lee');
// Jav
// Hyun
// Chung
// --------------------
```

- **부족한 파라미터** → 해당 값은 `undefined`로 동작.
- **초과한 아규먼트** → **무시**된다.

---

## 2) `arguments` 객체

함수 내부에는 **특별한 객체 `arguments`** 가 존재한다. 호출 시 **전달된 아규먼트들이 순서대로 담긴 유사 배열**이다.

```js
function printArgument(a, b, c) {
  console.log(arguments);
  console.log('--------------------');
}

printArgument('Ha', 'Chung', 'Ah');
// Arguments(3) ['Ha', 'Chung', 'Ah', callee: ƒ, Symbol(Symbol.iterator): ƒ]

printArgument('JavaScript');
// Arguments ['JavaScript', callee: ƒ, Symbol(Symbol.iterator): ƒ]

printArgument('Jav', 'Hyun', 'Chung', 'Lee');
// Arguments(4) ['Jav', 'Hyun', 'Chung', 'Lee', callee: ƒ, Symbol(Symbol.iterator): ƒ]
```

### 인덱싱/길이 확인

```js
function printArgument(a, b, c) {
  console.log(arguments[1]); // 두 번째 아규먼트
  console.log(arguments.length); // 전달된 아규먼트 개수
}

printArgument('Jav', 'Hyun', 'Chung', 'Lee');
// Hyun
// 4
```

- `arguments.length`로 **개수**를, `arguments[i]`로 **개별 값**을 확인할 수 있다.

### 순회

```js
function printArgument(a, b, c) {
  for (const arg of arguments) {
    console.log(arg);
  }
}

printArgument('Jav', 'Hyun', 'Chung', 'Lee');
// Jav
// Hyun
// Chung
// Lee
```

- `arguments`는 **배열이 아니지만(유사 배열)**, 위와 같이 **반복**하여 처리할 수 있다.

---

## 3) 주의 사항

- `arguments`는 **함수 내부의 특별한 이름**이므로, 파라미터/변수 이름을 `arguments`로 **사용하지 말자**(혼동/충돌 방지).

---

## 핵심 요약

- **아규먼트**는 호출 시 전달되는 실제 값, **파라미터**는 선언부 자리표시자.
- 아규먼트가 **모자라면 `undefined`**, **넘치면 무시**된다.
- 함수 내부의 `arguments` 객체로 **전달된 값들을 인덱싱/길이 확인/순회**할 수 있다.
- `arguments` 이름은 **내부 예약적 용도**이므로 별도 변수/파라미터로 사용하지 않는다.
