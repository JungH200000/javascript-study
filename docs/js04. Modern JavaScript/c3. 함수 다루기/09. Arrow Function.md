# Arrow Function

> **정의 한 줄 요약**: **Arrow Function**은 `function` 키워드 대신 `=>`를 사용해 **간결하게 함수(익명 함수)를 표현**하는 ES2015 문법이다.

---

## 기본 형태와 사용 맥락

Arrow Function은 보통 **변수에 할당**하거나, **다른 함수의 아규먼트(인자)** 로 넘길 때 사용한다.

### 변경 전(함수 표현식)

```js
const getTwice = function (number) {
  return number * 2;
};

console.log(getTwice(12));

const myBtn = document.querySelector('#myBtn');

myBtn.addEventListener('click', function () {
  console.log('button is clicked!');
});
```

### 변경 후(Arrow Function)

```js
const getTwice = (number) => {
  return number * 2;
};

console.log(getTwice(12));

const myBtn = document.querySelector('#myBtn');

myBtn.addEventListener('click', () => {
  console.log('button is clicked!');
});
```

- `function` → `=>`로 바뀌며, **동작은 동일**하다.
- `addEventListener` 예시처럼 **콜백 자리에 간결하게 표현**하기 좋다. _(실행 환경: 브라우저)_

---

## 더 간결한 표기(조건부로 가능)

함수 본문이 **`return` 한 줄**이면 `{}`와 `return`을 생략할 수 있다.

```js
/*
// 함수 선언식
function getTwice(number) {
  return number * 2;
}

// 함수 표현식
const getTwice = function (number) {
  return number * 2;
};
*/

// Arrow Function (간결 표기)
const getTwice = (number) => number * 2;

console.log(getTwice(12));
```

> 본문에 **조건/반복/대입 등** `return` 외 표현이 있으면 `{}`/`return`을 생략할 수 없다.

---

## 파라미터 괄호 생략 규칙

```js
const getTwice = (number) => {
  return number * 2;
};

/*
const getTwice = number => {
  return number * 2;
};
*/

console.log(getTwice(12));
```

- **파라미터가 1개**일 때만 `()` 생략 가능(예시의 주석 코드).
- **0개 또는 2개 이상**이면 `()`를 **반드시** 쓴다.

```js
const sum = (a, b) => {
  return a + b;
};

const getJS = () => {
  return { name: 'JavaScript' };
};

console.log(sum(10, 29));
console.log(getJS());
```

## 객체 리터럴을 반환할 때 주의

본문이 `return` 한 줄이더라도 **객체를 바로 반환**하려면 괄호로 감싸야 한다.

```js
const getJS = () => {
  return { name: 'JavaScript' };
};
```

아래처럼 쓰면 **오류**가 난다. `{}`를 **본문 블록**으로 해석하기 때문.

```js
const getJS = () => { name: 'JavaScript', };

console.log(getJS()); // Uncaught SyntaxError: Unexpected token
```

괄호로 감싸면 의도대로 **객체 리터럴 반환**이 된다.

```js
//prettier-ignore
const getJS = () => ({ name: 'JavaScript', });

console.log(getJS()); // {name: 'JavaScript'}
```

---

## `arguments` 객체와의 관계

Arrow Function에는 **`arguments` 객체가 없다**. 사용 시 에러가 발생한다.

```js
const arrowFunc = () => {
  console.log(arguments);
};

arrowFunc(1, 2, 3); // Uncaught ReferenceError: arguments is not defined
```

> 단, **Rest parameter**(`...args`)는 사용할 수 있다.
> (`arguments` 관련 더 자세한 차이는 별도 파트에서 다룸)

---

## 핵심 요약

- Arrow Function은 ES2015 문법으로, **간결한 함수 표현**을 제공한다.
- **본문이 `return` 한 줄**이면 `{}`와 `return`을 **생략**할 수 있다.
- **파라미터 1개만** 괄호 생략 가능(그 외는 `()` 필수).
- **객체 리터럴 반환** 시에는 **소괄호로 감싸서** 의도를 명확히 한다.
- Arrow Function에는 **`arguments`가 없다**(필요 시 Rest parameter 사용).
