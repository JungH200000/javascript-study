# this란 무엇인가? (what is `this`)

> **정의 한 줄 요약**: **`this`** 는 *함수가 어떻게 호출되었는지*에 따라 **가리키는 대상(객체)이 달라지는 특별한 키워드**이다.

---

## 1) 전역에서의 `this` (브라우저)

브라우저 환경에서 전역에서 `this`를 출력해 보면 전역 객체인 **`Window`** 가 나온다.

```js
console.log(this);
// → Window {window: Window, self: Window, document: document, ...}
```

- 요점: **브라우저 전역 컨텍스트의 기본 `this`는 `Window`**.

---

## 2) 메서드에서 `this`가 필요한 이유

아래 코드는 객체의 메서드 안에서 **특정 객체 이름**을 직접 참조하고 있다.

```js
const user = {
  firstName: 'Java',
  lastName: 'Script',
  getFullName: function () {
    return `${user.firstName}${user.lastName}`;
  },
};

console.log(user.getFullName()); // JavaScript
```

함수를 **외부로 분리**하면 문제가 생긴다. 여전히 `user`만 바라보기 때문이다.

```js
function getFullName() {
  return `${user.firstName}${user.lastName}`;
}

const user = {
  firstName: 'Java',
  lastName: 'Script',
  getFullName: getFullName,
};

const admin = {
  firstName: 'C',
  lastName: '++',
  getFullName: getFullName,
};

console.log(user.getFullName()); // JavaScript
console.log(admin.getFullName()); // JavaScript (⚠️ 여전히 user 기준)
```

### `this`로 일반화하기

**호출한 객체를 가리키는 `this`** 로 바꾸면 재사용이 가능해진다.

```js
function getFullName() {
  return `${this.firstName}${this.lastName}`;
}

const user = {
  firstName: 'Java',
  lastName: 'Script',
  getFullName: getFullName,
};

const admin = {
  firstName: 'C',
  lastName: '++',
  getFullName: getFullName,
};

console.log(user.getFullName()); // JavaScript
console.log(admin.getFullName()); // C++
```

- 요점: **메서드 내부에서는 `this`가 “그 메서드를 호출한 객체”** 를 가리킨다.

---

## 3) 일반 함수 호출에서의 `this`

그냥 함수를 호출하면(어떤 객체의 프로퍼티로서가 아닌 **일반 호출**) 브라우저에서는 전역 `this`가 나온다.

```js
console.log(this); // Window ...

function printThis() {
  console.log(this);
}

printThis(); // Window ...
```

반면, **객체의 메서드로서 호출**하면 `this`는 **그 객체**가 된다.

```js
function printThis() {
  console.log(this);
}

const myObj = {
  content: 'myObj',
  printThis: printThis,
};

const otherObj = {
  content: 'otherObj',
  printThis: printThis,
};

myObj.printThis(); // { content: 'myObj', printThis: ƒ }
otherObj.printThis(); // { content: 'otherObj', printThis: ƒ }
```

- 요점: **같은 함수여도 “호출 방식”에 따라 `this`가 달라진다.**

---

## 4) Arrow Function에서의 `this`

Arrow Function은 **선언 시점의 `this`를 그대로 사용**한다(호출한 대상에 따라 바뀌지 않음).

```js
console.log(this); // Window ...

const printThis = () => {
  console.log(this);
};

const myObj = {
  content: 'myObj',
  printThis: printThis,
};

const otherObj = {
  content: 'otherObj',
  printThis: printThis,
};

myObj.printThis(); // Window ...
otherObj.printThis(); // Window ...
```

- 위 코드에서 Arrow Function이 **선언되기 직전의 `this`가 Window**였기 때문에, 어느 객체에서 호출하든 **항상 Window**가 출력된다.
- 요점: **객체의 메서드에는 보통 일반 함수(함수 표현식/선언)를 사용**하는 편이 안전하다. _(Arrow Function은 `this`가 고정되기 때문)_

---

## 핵심 요약

- **브라우저 전역**에서 `this`는 기본적으로 **`Window`**.
- **메서드 호출** 시 `this`는 **그 메서드를 호출한 객체**.
- **일반 함수 호출** 시(브라우저) `this`는 **전역(`Window`)**.
- **Arrow Function**은 **선언 시점의 `this`를 캡처**하여 **호출 대상에 따라 바뀌지 않는다**.
- 따라서 **객체 메서드**에는 **일반 함수 사용**이 권장된다.
