# 함수를 만드는 방법

> **정의 한 줄 요약**: 함수는 **이름으로 동작을 묶어 재사용**하는 단위다. JavaScript에서는 **함수 선언**과 **함수 표현식** 두 방식으로 만들 수 있으며, **호이스팅·스코프 동작이 다르다**.

---

## 함수 선언 (Function Declaration)

```js
function 함수이름() {
  동작...
}
```

- **파라미터/반환**: 호출 시 값을 `()` 안에 전달(파라미터), 필요하면 `return`으로 값을 돌려준다.
- 이 문법 자체를 **함수 선언**이라고 부른다.

---

## 함수 표현식 (Function Expression)

```js
const printChung = function () {
  console.log('Chung');
};

printChung(); // Chung
```

- **함수를 값처럼** 변수에 담아 사용하는 방식이 **함수 표현식**이다.
- 아래처럼 **인수로 함수(익명 함수)를 전달**하는 형태도, 함수를 값처럼 쓰는 **함수 표현식**에 해당한다.

```js
const myBtn = document.querySelector('#myBtn');

myBtn.addEventListener('click', function () {
  console.log('button is clicked');
});
```

> 정리: “변수에 담느냐”가 본질이 아니라, **함수를 값처럼 쓰면 함수 표현식**이다.

---

## 함수 선언 vs 함수 표현식

### 1) 호이스팅(선언 전 호출 가능 여부)

```js
// 함수 선언: 선언 이전 호출 가능 (호이스팅)
printChung(); // Chung

function printChung() {
  console.log('Chung');
}
```

```js
// 함수 표현식: 변수 특성상 선언 이전 접근 불가
printChung(); // ReferenceError: Cannot access 'printChung' before initialization

const printChung = function () {
  console.log('Chung');
};
```

- **함수 선언**은 선언이 끌어올려져 **선언 전에도 호출**될 수 있다.
- **함수 표현식**은 변수를 통해 접근하므로 **선언 전 접근 불가**다.

### 2) 스코프(유효 범위)

- 글의 요지: **함수 선언**은 `var`와 유사하게 **함수 단위의 스코프**를 가진다.
  아래 예시처럼 **함수 내부 선언은 함수 밖에서 호출 불가**이며, 블록(`if`, 중괄호 등) 안에서의 함수 선언/호출 예시가 이어진다.

```js
const x = 4;

if (x < 5) {
  function printJS() {
    console.log('JavaScript');
  }
}

{
  function printChung() {
    console.log('Chung');
  }
}

printChung(); // Chung
printJS(); // JavaScript
```

- **함수 표현식**은 **할당된 변수의 스코프 규칙을 따른다**.

```js
var printJS = function () {
  console.log('JavaScript');
};

let printHello = function () {
  console.log('Hello!');
};

const printChung = function () {
  console.log('Chung');
};
```

---

## 어떤 방식을 쓸까?

- 글의 결론: **두 방식 모두 가능**하나, **일관된 스타일**을 택해 쓰자.
- 개념을 설명하는 문맥에서는 **함수 선언을 우선**해 사용하겠다.

---

## 핵심 요약

- 함수는 **선언**과 **표현식** 두 방식으로 만들 수 있다.
- **호이스팅**: 함수 선언은 **선언 전 호출 가능**, 함수 표현식은 **불가**.
- **스코프**: 함수 선언은 글의 요지대로 **함수 단위**, 함수 표현식은 **변수 스코프**를 따른다.
- 팀/문서 맥락에서 **일관된 방식**을 정해 쓰는 것이 좋다.
