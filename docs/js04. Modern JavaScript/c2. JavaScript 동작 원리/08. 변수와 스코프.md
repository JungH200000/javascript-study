# 변수와 스코프

> **정의 한 줄 요약**: 변수는 **이름으로 값을 다루는 기본 추상화 수단**이며, JavaScript에서는 선언 키워드(`var`/`let`/`const`)에 따라 **사용 가능 시점(호이스팅 차이)** 과 **유효 범위(스코프)** 가 달라진다.

---

## ES2015 전후: `var` vs `let`/`const`

- 과거엔 `var`만 있었고, 이로 인한 몇 가지 문제가 있었다.
- ES2015에서 `let`, `const`가 도입되어 **재할당 필요 시 `let`**, **재할당 불필요 시 `const`** 사용이 권장된다.

---

## 1. 변수가 유효한 시점의 차이(호이스팅)

`var` 선언은 **선언부만 끌어올려지는(hoisting)** 특성 때문에, 선언 전 접근 시에도 에러가 아닌 `undefined`가 나온다.

```js
console.log(title); // undefined
var title;
```

선언과 동시에 할당해도 **선언만** 끌어올려지므로, 초기값은 나중에 적용된다.

```js
console.log(title); // undefined
var title = 'chung';
console.log(title); // chung
```

반면 `let`/`const`는 **선언 이전 접근 불가**다. 아래 코드는 에러가 난다.

```js
console.log(title);
let title;
// ReferenceError: Cannot access 'title' before initialization
```

> 포인트: 예상치 못한 동작 대신 **명확한 에러**가 나므로 원인 파악이 쉽다.

---

## 2. 중복 선언

`var`는 **중복 선언 가능**하다(의도치 않은 값 덮어쓰기 위험).

```js
var title = 'chung';
console.log(title); // chung
var title = 'haha';
console.log(title); // haha
```

`let`/`const`는 **중복 선언 불가**다.

```js
let title = 'chung';
console.log(title); // chung
let title = 'haha'; // SyntaxError: Identifier 'title' has already been declared
console.log(title);
```

---

## 3. 스코프(유효 범위)의 차이

### 함수 스코프(`var`)

`var`는 **함수 단위**로 스코프가 구분된다.

```js
var x = 3; // Global Variable

function myFunc() {
  var y = 4; // Local Variable

  console.log(`x in myFunc: ${x}`); // 3
  console.log(`y in myFunc: ${y}`); // 4
}

myFunc();
console.log(x); // 3
console.log(y); // ReferenceError: y is not defined
```

조건문/반복문 **블록 내부에서의 `var`** 는 **블록 밖에서도 접근 가능**하다.

```js
var x = 3;

if (x < 4) {
  var y = 3;
}

for (var i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}

console.log('x: ', x); // 3
console.log('y: ', y); // 3
console.log('i: ', i); // 5
```

### 블록 스코프(`let`/`const`)

`let`/`const`는 **중괄호 `{}` 블록 기준**으로 스코프가 구분된다.

```js
let x = 3;

if (x < 4) {
  let y = 3;
}

for (let i = 0; i < 5; i++) {
  console.log(i); // 0, 1, 2, 3, 4
}

console.log('x: ', x); // 3
console.log('y: ', y); // ReferenceError: y is not defined
console.log('i: ', i); // ReferenceError: i is not defined
```

단순 블록만으로도 스코프가 생긴다.

```js
{
  let title = 'Chung';
  console.log(title); // Chung
}

console.log(title); // ReferenceError: title is not defined
```

> 정리: `var`는 **함수 스코프**, `let`/`const`는 **블록 스코프**를 가진다.

---

## 핵심 요약

- `var`는 선언이 끌어올려져 **선언 전 접근 시 `undefined`**, `let`/`const`는 **에러**가 난다.
- `var`는 **중복 선언 가능**, `let`/`const`는 **불가**.
- 스코프: `var`는 **함수 단위**, `let`/`const`는 **블록 단위**.
- 조건문/반복문 블록 밖 접근: `var`는 **가능**, `let`/`const`는 **불가**.
