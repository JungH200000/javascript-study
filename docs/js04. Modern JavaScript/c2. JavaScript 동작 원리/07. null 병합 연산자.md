# null 병합 연산자 `??`

> **정의 한 줄 요약**: `??`는 **왼쪽 값이 `null` 또는 `undefined`일 때만** 오른쪽 값을 선택한다. (그 외 값이면 **왼쪽 값을 그대로 사용**)

---

## 동작 원리와 예시

```js
const example1 = null ?? 'I'; // I
const example2 = undefined ?? 'love'; // love
const example3 = 'Chung' ?? 'JavaScript'; // 'Chung'이 null/undefined가 아니므로 그대로 반환

console.log(example1, example2, example3); // I love Chung
```

- 왼쪽이 **nullish(null/undefined)** → **오른쪽** 선택
- 왼쪽이 nullish **아님** → **왼쪽** 그대로

---

## OR 연산자(`||`)와의 비교

둘 다 “왼쪽이 특정 조건이면 오른쪽을 고른다”는 점에서 비슷해 보이지만 **기준이 다르다**:

- `??`는 **null/undefined** 여부만 본다.
- `||`는 **Falsy** 여부를 본다. (`false`, `0`, `''`, `NaN`, `null`, `undefined` 등)

```js
// 동일하게 동작하는 경우
const title1 = null || 'hello';
const title2 = null ?? 'world';

console.log(title1); // hello
console.log(title2); // world
```

```js
// 다른 결과가 나는 경우 (0은 Falsy이지만 nullish는 아님)
const width1 = 0 || 150; // 150  ← Falsy라서 오른쪽 선택
const width2 = 0 ?? 150; // 0    ← null/undefined가 아니므로 왼쪽 유지

console.log(width1); // 150
console.log(width2); // 0
```

---

## 핵심 요약

- `??`: **null/undefined**일 때만 오른쪽 값을 사용한다.
- `||`: **Falsy**이면 오른쪽 값을 사용한다(0, 빈 문자열 등도 포함).
- 따라서 **기본값 설정 시** `0`, `''` 같은 유효 값은 유지하고 싶다면 `??`를, **아예 “참 같은 값”만 원한다면** `||`를 쓰면 된다.
