# 불린인 듯 불린 아닌 불린같은 값

> **정의 한 줄 요약**: JavaScript에서는 **불린이 아닌 값도** 조건식 맥락에서 **불린으로 평가**된다. 이때 `false`처럼 평가되는 값을 **Falsy**, `true`처럼 평가되는 값을 **Truthy**라고 한다.

---

## 1) 조건식에서의 불린 평가(암묵적 변환)

아래의 예시는 **불린이 아닌 값**(문자열)이 **조건식에서 불린처럼 평가**되는 모습을 보여준다.

```js
if ('study') {
  console.log('I like study!');
} else {
  console.log('what the fxxx!');
}
```

**설명**

- 조건식의 `'study'`는 **Truthy**로 평가되어 `if` 블록이 실행된다.
- 결과적으로 콘솔에는 `I like study!`가 출력된다.

---

## 2) 불린이 필요한 맥락의 예

다음과 같은 자리에 들어가는 표현식은 **불린으로 평가**된다.

```js
if (조건부분) {...}
for (...;조건부분;...) {...}
while (조건부분) {...}
```

---

## 3) Truthy / Falsy 정리

- **Falsy**로 평가되는 값: `false`, `null`, `undefined`, `NaN`, `0`, `''`(빈 문자열)
- **Truthy**로 평가되는 값: 위 Falsy 값을 **제외한 나머지 모든 값**

  - 주의: `[]`(빈 배열), `{}`(빈 객체)는 **Truthy**다(종종 Falsy로 오해함).

---

## 4) 불린으로 직접 확인하기

특정 값이 불린으로 어떻게 해석되는지 알고 싶다면 **`Boolean()` 함수**로 **직접 변환**해 확인할 수 있다.

- Falsy 값들은 `false`를, 그 외 값들은 `true`를 반환한다.

---

## 핵심 요약

- 조건식이 필요한 자리에서는 **불린이 아닌 값도** 불린으로 **자동 평가**된다.
- **Falsy**: `false`, `null`, `undefined`, `NaN`, `0`, `''`; **그 외는 Truthy**.
- `[]`, `{}`는 **Truthy**다(오해 주의).
- 값의 불린 해석은 **`Boolean()`** 변환으로 직접 확인할 수 있다.
