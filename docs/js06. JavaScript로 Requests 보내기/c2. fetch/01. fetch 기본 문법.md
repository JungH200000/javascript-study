# fetch 기본 문법

> **정의**: **fetch**는 URL에 HTTP 요청을 보내고, **Promise**로 **Response**(응답) 객체를 돌려주는 **표준 Web API**입니다.
> **한 줄 요약**: `fetch(url)` → 응답이 오면 `Response`를 받고, **`await res.json()`** 같은 메서드로 **본문(body)** 를 읽습니다.

> **사전 준비**
> 모듈 최상위에서 `await`을 쓰려면 프로젝트의 `package.json`에 `"type": "module"`을 설정합니다.
> (`import`, `export` 문법 사용 전제)

---

## 1) 첫 요청: Response 객체 살펴보기

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');

console.log(res);
```

**설명(핵심 포인트)**

- `fetch('...')` : 기본적으로 **GET 요청**을 보냅니다.
- `fetch(...)`는 **Promise**를 반환 → `await`으로 **Response** 객체를 받습니다.
- `console.log(res)` : 응답의 **상태/헤더/바디 등 메타 정보**를 한 번에 확인합니다.

**실행 예**

```terminal
Response {
  status: 200,
  statusText: 'OK',
  headers: Headers {
    date: 'Sat, 11 Oct 2025 06:42:44 GMT',
    'content-type': 'application/json; charset=utf-8',
    'transfer-encoding': 'chunked',
    connection: 'keep-alive',
    'x-powered-by': 'Express',
    vary: 'Origin, Accept-Encoding',
    'access-control-allow-credentials': 'true',
    etag: 'W/"44e-jVKLwA09h5fLsUjT2Ugk2VW1MgE"',
    'content-encoding': 'gzip'
  },
  body: ReadableStream { locked: false, state: 'readable', supportsBYOB: true },
  bodyUsed: false,
  ok: true,
  redirected: false,
  type: 'basic',
  url: 'https://learn.codeit.kr/api/color-surveys'
}
```

- 실무에서 자주 보는 건 **`status`(상태 코드)**, **`headers`(헤더)**, **`body`(본문)** 입니다.

## 2) 상태 코드와 헤더 꺼내기

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');

console.log('Status Code: ');
console.log(res.status);

console.log();

console.log('Headers: ');
console.log(res.headers);
```

**설명(핵심 포인트)**

- `res.status` : **상태 코드**(예: `200`)
- `res.headers` : **헤더 모음**(예: `content-type`, `etag` 등)

**실행 예**

```terminal
Status Code:
200

Headers:
Headers {
```

## 3) 본문(body) 읽기: JSON

> **본문은 프로퍼티로 직접 읽지 않고, 메서드로 읽는다.**
> 문자열이면 `text()`, **JSON이면 `json()`** 을 사용.

- 헤더의 `'content-type': 'application/json; ...'` 이므로 **JSON 본문**입니다.
- `res.json()`은 **Promise**를 반환하므로 **`await`** 이 필요합니다.

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');
const data = await res.json();

console.log(data);
```

**설명(핵심 포인트)**

- `await res.json()` : 본문(JSON 문자열)을 **JS 객체**로 변환하여 반환.

**실행 예**

```terminal
{
  count: 118,
  next: 'https://learn.codeit.kr/api/color-surveys/?offset=10&limit=10',
  previous: null,
  results: [
    {
      createdAt: 1760031287000,
      updatedAt: 1760031287000,
      colorCode: '#9542F5',
      id: 126,
      mbti: 'ENTP'
    },
    ...
    {
      createdAt: 1759831040000,
      updatedAt: 1759831040000,
      colorCode: '#ABCDEF',
      id: 117,
      mbti: 'INFP'
    }
  ]
}
```

> 실제 설문 데이터 외에 `count`, `next`, `previous` 같은 필드도 포함되어 있습니다.

## 4) 결과 다루기: 구조 분해(Destructuring)로 꺼내기

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');
const data = await res.json();

const { results } = data;
const survey01 = results[0];
const { id, mbti, colorCode, createdAt, updatedAt } = survey01;

console.log(survey01);
console.log(id, mbti, colorCode, createdAt, updatedAt);
```

**설명(핵심 포인트)**

- `const { results } = data;` : `data.results`를 **구조 분해**로 추출.
- `results[0]` : 첫 번째 설문 객체.
- `{ id, mbti, ... } = survey01` : 필요한 **프로퍼티만 간편 추출**.

**실행 예**

```terminal
{
  createdAt: 1760031287000,
  updatedAt: 1760031287000,
  colorCode: '#9542F5',
  id: 126,
  mbti: 'ENTP'
}
126 ENTP #9542F5 1760031287000 1760031287000
```
