# 다양한 GET 요청 보내기

> **정의**: **Query string**은 URL의 `?key=value` 형식으로 **추가 조건(파라미터)** 을 전달하는 부분입니다.
> **한 줄 요약**: `?mbti=ISTJ&offset=10&limit=10`처럼 붙여 보내면 **필터/페이지네이션**을 제어할 수 있습니다.

---

## 1) 사용할 수 있는 파라미터와 페이지네이션

- 사용 가능 파라미터: **`id`**, **`limit`**, **`offset`**, **`mbti`**

  - `mbti` : 해당 MBTI 설문만 **필터**
  - `limit` / `offset` : **페이지네이션**(모든 데이터를 한 번에가 아니라 **나눠** 받아오기)

> **페이지네이션 핵심** > `offset` = **앞에서 몇 개 건너뛸지**, `limit` = **이번에 몇 개 가져올지**.

---

## 2) 기본 목록 요청과 응답 구조 재확인

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');
const data = await res.json();

console.log(data);
```

```terminal
{
  count: 118,
  next: 'https://learn.codeit.kr/api/color-surveys/?offset=10&limit=10',
  previous: null,
  results: [
    {
      createdAt: 1760031287000,
      updatedAt: 1760031287000,
      colorCode: '#9542F5',
      id: 126,
      mbti: 'ENTP'
    },
    ...
    {
      createdAt: 1759831040000,
      updatedAt: 1759831040000,
      colorCode: '#ABCDEF',
      id: 117,
      mbti: 'INFP'
    }
  ]
}
```

**응답 필드 의미**

- `count`: 전체 데이터 개수
- `next`: **다음 페이지** URL
- `previous`: **이전 페이지** URL
- `results`: **현재 페이지 데이터 배열**

처음 10개를 받았으니, 다음은 **처음에서 10개 건너뛴 뒤 10개**를 요청해야 하므로 `next`가
`https://learn.codeit.kr/api/color-surveys/?offset=10&limit=10` 입니다.

## 5) `URL` 객체로 query string 조립하기

먼저 URL 객체를 만들고:

```js
// src/js06-js-requests/main.js
const url = new URL('https://learn.codeit.kr/api/color-surveys');
...
```

`searchParams`에 파라미터를 추가합니다:

```js
// src/js06-js-requests/main.js
const url = new URL('https://learn.codeit.kr/api/color-surveys');
url.searchParams.append('offset', 5);
url.searchParams.append('limit', 5);
...
```

이제 `fetch`에 **URL 객체**를 넘깁니다:

```js
// src/js06-js-requests/main.js
const url = new URL('https://learn.codeit.kr/api/color-surveys');
url.searchParams.append('offset', 5);
url.searchParams.append('limit', 5);

const res = await fetch(url);
const data = await res.json();

console.log(data);
```

```terminal
{
  count: 118,
  next: 'https://learn.codeit.kr/api/color-surveys/?offset=10&limit=5',
  previous: 'https://learn.codeit.kr/api/color-surveys/?offset=0&limit=5',
  results: [
    {
      createdAt: 1759833706000,
      updatedAt: 1759833706000,
      colorCode: '#ABCDEF',
      id: 121,
      mbti: 'INFP'
    },
    ...
    {
      createdAt: 1759831040000,
      updatedAt: 1759831040000,
      colorCode: '#ABCDEF',
      id: 117,
      mbti: 'INFP'
    }
  ]
}
```

- **`offset=5`, `limit=5`** 조건이 반영된 결과가 반환됩니다.

## 6) 다시 기본 목록 코드로 되돌리기

```js
// src/js06-js-requests/main.js
const res = await fetch('https://learn.codeit.kr/api/color-surveys');
const data = await res.json();

console.log(data);
```

> `GET '/api/color-surveys'`는 **여러 설문 객체**를,
> `GET 'api/color-surveys/:id'`는 **단일 설문 객체**를 가져오는 데 사용됩니다.

---

## 7) 단일 설문 하나만 가져오기 (`:id`)

const res = await fetch('https://learn.codeit.kr/api/color-surveys/10');
