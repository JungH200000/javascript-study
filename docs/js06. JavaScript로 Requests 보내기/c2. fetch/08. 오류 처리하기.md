# 오류 처리하기

**정의**: **오류 처리(error handling)** 는 네트워크 요청 중 발생할 수 있는 실패 상황을 **감지하고 대응**하는 과정입니다.
**한 줄 요약**: `try...catch`로 **요청 자체 실패**를 잡고, `res.ok`로 **HTTP 에러 응답(4xx/5xx)** 도 **명시적으로 예외**로 다룹니다.

---

## 1) 요청 자체가 실패하는 경우 (잘못된 URL 등)

아래처럼 **의도적으로 잘못된 주소**를 넣고 실행해 봅니다.

```js
// src/js06-js-requests/api.js

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const url = new URL('https://learn.codeit.krError/api/color-surveys'); // ← 오타로 '요청 자체 실패' 유도
  Object.keys(params).forEach((key) => {
    url.searchParams.append(key, params[key]);
  });

  const res = await fetch(url); // 여기서 네트워크 레벨 오류 발생
  const data = await res.json(); // 실행되지 않음(위에서 reject)

  return data;
}
```

```js
// src/js06-js-requests/main.js
import { getColorSurveys } from './api.js';

// GET /api/color-surveys
const data = await getColorSurveys();

console.log('GET /api/color-surveys');
console.log(data);
```

**실행 결과**

```terminal
TypeError: fetch failed
...
[cause]: Error: getaddrinfo ENOTFOUND learn.codeit.krerror
```

- 주소를 찾지 못해 **요청 자체가 실패**했고, `fetch`가 반환한 **Promise는 Rejected** 가 됩니다.

---

## 2) `try...catch`로 호출부에서 오류 잡기

호출하는 쪽을 `try...catch`로 감싸면, **요청 자체 실패**를 잡아 처리할 수 있습니다.

```js
// src/js06-js-requests/main.js
import { getColorSurveys } from './api.js';

// GET /api/color-surveys
console.log('GET /api/color-surveys');

try {
  const data = await getColorSurveys(); // 내부에서 실패 → catch로 이동
  console.log(data);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.message); // 'fetch failed'
}
```

**실행 결과**

```terminal
GET /api/color-surveys
오류가 발생했습니다.
fetch failed
```

> 설명: `try` 안에서 던져진 오류를 `catch`가 받아 처리합니다. 실제 웹사이트라면 콘솔 대신 화면에 메시지를 보여줄 수 있습니다.

---

## 3) HTTP 에러 응답(4xx/5xx)은 기본적으로 **Fulfilled** 이다

- **중요 포인트**

  - **요청 자체 실패**(잘못된 URL, 유효하지 않은 헤더 등)만 **Rejected**.
  - **HTTP 에러 응답(예: 400, 500)** 은 **응답은 왔기 때문에** `fetch` **Promise는 Fulfilled** 입니다.

- 따라서 **상태 코드가 성공이 아닐 때 직접 예외를 던져** 깔끔히 처리합니다.

```js
// src/js06-js-requests/api.js

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const url = new URL('https://learn.codeit.krError/api/color-surveys'); // 데모용 잘못된 URL
  Object.keys(params).forEach((key) => {
    url.searchParams.append(key, params[key]);
  });

  const res = await fetch(url);

  if (!res.ok) {
    // 2xx가 아니면
    throw new Error('데이터를 불러오는데 실패했습니다.'); // 명시적으로 예외 발생
  }

  const data = await res.json();
  return data;
}
```

- `res.ok` 는 상태 코드가 **2xx** 이면 `true`, 아니면 `false`.

## 4) 잘못된 파라미터로 4xx 응답 받기(예: `mbti: 'AAAA'`)

주소를 **정상 URL**로 되돌리고, **유효하지 않은 mbti** 를 보냅니다.

```js
// src/js06-js-requests/main.js
import { getColorSurveys } from './api.js';

console.log('GET /api/color-surveys');

try {
  const data = await getColorSurveys({ mbti: 'AAAA' }); // 서버가 400 등 에러 응답
  console.log(data);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.message); // '데이터를 불러오는데 실패했습니다.'
}
```

**실행 결과**

```terminal
GET /api/color-surveys
오류가 발생했습니다.
데이터를 불러오는데 실패했습니다.
```

- **요청 자체 실패가 아니어도**, `!res.ok` 분기에서 **예외를 던졌기 때문에** 호출부는 동일하게 `catch` 에서 처리할 수 있습니다.

## 5) 최종: 모든 API 함수에 동일한 패턴 적용

```js
// src/js06-js-requests/api.js

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const url = new URL('https://learn.codeit.kr/api/color-surveys'); // 정상 URL
  Object.keys(params).forEach((key) => {
    url.searchParams.append(key, params[key]);
  });

  const res = await fetch(url);

  if (!res.ok) {
    throw new Error('데이터를 불러오는데 실패했습니다.');
  }

  const data = await res.json();
  return data;
}

// GET /api/color-surveys/:id
export async function getColorSurvey(id) {
  const res = await fetch(`https://learn.codeit.kr/api/color-surveys/${id}`);

  if (!res.ok) {
    throw new Error('데이터를 불러오는데 실패했습니다.');
  }

  const data = await res.json();
  return data;
}

// POST /api/color-surveys
export async function createColorSurvey(surveyData) {
  const res = await fetch('https://learn.codeit.kr/api/color-surveys', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(surveyData),
  });

  if (!res.ok) {
    throw new Error('데이터를 생성하는데 실패했습니다.');
  }

  const data = await res.json();
  return data;
}
```

---

## 정리

1. **두 가지 실패 유형**

   - (1) **요청 자체 실패**: 잘못된 URL/헤더 등 → **Promise Rejected** (`fetch failed`).
   - (2) **HTTP 에러 응답**: 400/500 등 → **Promise Fulfilled** (응답 객체 반환).

2. **깔끔한 처리 방법**

   - (1)은 `try...catch` 로 잡고,
   - (2)는 `if (!res.ok) throw ...` 로 **명시적 예외**를 던져 호출부에서 **항상 동일한 방식**으로 처리.

3. **주의점**

   - 에러 응답의 body가 JSON이면 `res.json()` 이 **성공**할 수 있어 헷갈립니다.
   - 그래서 **상태 코드 기준**으로 먼저 실패를 판별하고, 그 외에는 정상 데이터만 반환하도록 **일관화**합니다.
