# POST request 보내기

`fetch` 함수는 기본적으로 GET request를 보낸다. 그러면 POST 등 다른 종류의 request는 어떻게 보낼 수 있을까??

`fetch` 함수의 두 번째 argument로 다양한 옵션을 넘겨줄 수 있다. POST request를 보내려면 옵션의 `method` property를 `POST`로 설정하면 된다.

```js
// src/js06-js-requests/main.js
fetch('https://learn.codeit.kr/api/color-surveys', {
  method: 'POST',
});
```

꼭 `POST`가 아니더라도 `PATCH`나 `DELETE`를 설정해줄 수 있다.

POST request는 보통 body를 같이 전달한다. Color Survey API의 경우 `mbti`, `colorCode`, `password`를 body로 전달해야 한다.

여기서 `password`는 설문 객체를 생성한 사람만이 나중에 수정/삭제를 가능하게 하는 용도이다. request body도 옵션으로 `body`라는 property로 설정하면 된다.

```js
// src/js06-js-requests/main.js
const surveyData = {
  mbti: 'ENFP',
  colorCode: '#ABCDEF',
  password: '0000',
};

fetch('https://learn.codeit.kr/api/color-surveys', {
  method: 'POST',
  body: JSON.stringify(surveyData),
});
```

그리고 여기서 중요한 부분이 있다. `surveyData`는 JavaScript 객체이고 외부로 데이터를 주고 받을 때는 JSON 문자열을 사용한다. 그래서 `surveyData`를 JSON 문자열로 변환해줘야 한다. => `JSON.stringify(surveyData)`

JavaScript 객체를 JSON 문자열로 변환할 수 있다.

마지막으로 데이터를 보낼 때는 `Content-type` 헤더로 어떤 형식의 데이터를 보내는 것인지 알려주는 것이 좋다. `header` property로 헤더까지 설정해보겠다.

```js
// src/js06-js-requests/main.js
const surveyData = {
  mbti: 'ENFP',
  colorCode: '#ABCDEF',
  password: '0000',
};

fetch('https://learn.codeit.kr/api/color-surveys', {
  method: 'POST',
  headers: {
    'Content-type': 'application/json',
  },
  body: JSON.stringify(surveyData),
});
```

필요하다면 다른 헤더들도 아래에 더 추가할 수 있다.

---

이제 POST request를 보낼 준비는 끝났다. response를 처리하는 코드도 작성해주자. GET request와 완전히 동일하다.

```js
// src/js06-js-requests/main.js
const surveyData = {
  mbti: 'ENFP',
  colorCode: '#ABCDEF',
  password: '0000',
};

const res = await fetch('https://learn.codeit.kr/api/color-surveys', {
  method: 'POST',
  headers: {
    'Content-type': 'application/json',
  },
  body: JSON.stringify(surveyData),
});

const data = await res.json();

console.log(data);
```

POST request로 데이터를 생성하면 서버가 생성된 데이터를 response로 돌려주는 경우가 많다. `json` 메소드로 response를 파싱해서 출력해보자. 코드를 실행해보면

```terminal
{
  createdAt: 1760177582871,
  updatedAt: 1760177582871,
  colorCode: '#ABCDEF',
  id: 127,
  mbti: 'ENFP',
  password: '0000'
}
```

새로 생성된 설문 객체가 잘 돌아온다.

실제 웹 개발을 하는 상황이라고 생각해보면 사용자가 form에 mbti와 좋아하는 색상 정보를 입력하면 그 값으로 `serveyData` 같은 객체를 만들고 그것을 POST request의 body에 전달해서 설문 결과를 생성하는 것이다.

그리고 생성된 결과가 response로 돌아오면 그것을 화면에 보여주는 등을 할 수 있을 것이다.
