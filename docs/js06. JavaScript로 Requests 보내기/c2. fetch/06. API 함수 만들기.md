# API 함수 만들기

**정의**: *API 호출 함수*는 반복되는 `fetch` 호출 로직을 **재사용 가능한 함수**로 묶어 모듈로 분리한 것입니다.
**한 줄 요약**: 자주 쓰는 **GET/POST 요청**을 `api.js`로 모듈화하고, **필요한 곳에서 import 하여 호출**합니다.

---

## 1) 이때까지 작성한 코드

```js
// GET /api/color-surveys
const url = new URL('https://learn.codeit.kr/api/color-surveys');
url.searchParams.append('offset', 5);
url.searchParams.append('limit', 5);

const res = await fetch(url);
const data = await res.json();

console.log(data);
```

```js
// GET /api/color-surveys/:id
const res = await fetch('https://learn.codeit.kr/api/color-surveys/10');
const data = await res.json();

console.log(data);
```

```js
// POST /api/color-surveys
const surveyData = {
  mbti: 'ENFP',
  colorCode: '#ABCDEF',
  password: '0000',
};

const res = await fetch('https://learn.codeit.kr/api/color-surveys', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify(surveyData),
});

const data = await res.json();

console.log(data);
```

## 2) `api.js`로 모듈화

### (1) 목록 조회: `GET /api/color-surveys`

```js
// src/js06-js-requests/api.js

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const url = new URL('https://learn.codeit.kr/api/color-surveys');

  // params의 key-value를 쿼리스트링으로 추가
  Object.keys(params).forEach((key) => {
    url.searchParams.append(key, params[key]);
  });

  const res = await fetch(url); // 네트워크 요청
  const data = await res.json(); // JSON 본문 파싱
  return data; // 호출부로 결과 반환
}
```

### (2) 단일 조회: `GET /api/color-surveys/:id`

```js
// src/js06-js-requests/api.js

// GET /api/color-surveys/:id
export async function getColorSurvey(id) {
  const res = await fetch(`https://learn.codeit.kr/api/color-surveys/${id}`);
  const data = await res.json();
  return data;
}
```

### (3) 생성: `POST /api/color-surveys`

```js
// src/js06-js-requests/api.js

// POST /api/color-surveys
export async function createColorSurvey(surveyData) {
  const res = await fetch('https://learn.codeit.kr/api/color-surveys', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json', // JSON 전송 형식 명시
    },
    body: JSON.stringify(surveyData), // 객체 → JSON 문자열
  });
  const data = await res.json();
  return data;
}
```

## 3) `main.js`에서 사용하기

```js
// src/js06-js-requests/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './api.js';

// GET /api/color-surveys
const idsData = await getColorSurveys({ offset: 20, limit: 20 });

// GET /api/color-surveys/:id
const idData = await getColorSurvey(13);

// POST /api/color-surveys
const surveyData = {
  mbti: 'ENFP',
  colorCode: '#ABCDEF',
  password: '0000',
};
const postData = await createColorSurvey(surveyData);

console.log('GET /api/color-surveys');
console.log(idsData);

console.log('GET /api/color-surveys/:id');
console.log(idData);

console.log('POST /api/color-surveys');
console.log(postData);
```
