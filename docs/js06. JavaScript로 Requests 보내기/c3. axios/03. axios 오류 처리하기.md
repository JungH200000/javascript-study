# axios 오류 처리하기

**정의**: **axios**는 **2xx가 아닌 응답(4xx/5xx)** 도 **Promise를 Rejected 상태로** 돌려주는 HTTP 클라이언트입니다.
**한 줄 요약**: `try...catch` 하나로 **요청 실패**와 **HTTP 에러 응답**을 **모두** 잡아 처리할 수 있습니다.

---

## 1) fetch와의 차이

- **fetch**: **요청 자체가 실패**할 때만 Rejected. **4xx/5xx 응답은 Fulfilled**(응답 객체 반환).
- **axios**: **4xx/5xx 응답도 Rejected**. **2xx 응답만 Fulfilled**. → 오류 처리 **편리**.

---

## 2) `try...catch`로 axios 호출 감싸기

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

...
// GET /color-surveys/:id
console.log('GET /color-surveys/:id');
try {
  const survey = await getColorSurvey(12345);

  console.log(survey);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.message);
}
```

**실행 예**

```terminal
GET /color-surveys/:id
오류가 발생했습니다.
Request failed with status code 404
```

- axios가 **에러 메시지**(`error.message`)를 자동으로 설정해 줍니다.

---

## 3) 에러 응답 전체 살펴보기: `error.response`

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

...
// GET /color-surveys/:id
console.log('GET /color-surveys/:id');
try {
  const survey = await getColorSurvey(12345);

  console.log(survey);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.response);
}
```

**실행 예**

```terminal
GET /color-surveys/:id
오류가 발생했습니다.
{
  status: 404,
  statusText: 'Not Found',
  headers: Object [AxiosHeaders] { ... },
  config: { ... },
  request: <ref *1> ClientRequest { ... },
  data: ''
}
```

- `error.response`에는 **`status`**, **`headers`**, **`data`** 등이 포함됩니다.

---

## 4) 자주 쓰는 값만 뽑기: `status`, `data`

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

...
// GET /color-surveys/:id
console.log('GET /color-surveys/:id');
try {
  const survey = await getColorSurvey(12345);

  console.log(survey);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.response.status);
  console.log(error.response.data);
}
```

**실행 예**

```terminal
GET /color-surveys/:id
오류가 발생했습니다.
404

```

- 응답 바디가 비어 있으면 `data`가 빈 문자열로 보일 수 있습니다.

## 5) POST에서도 동일: 필수 값 누락 시 400

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

...
// POST /color-surveys
console.log('POST /color-surveys');
const surveyData = {
  mbti: 'ISFP',
  password: '0000',
};

try {
  const newColorSurvey = await createColorSurvey(surveyData);

  console.log(newColorSurvey);
} catch (error) {
  console.log('오류가 발생했습니다.');
  console.log(error.response.status);
  console.log(error.response.data);
}
```

**실행 예**

```terminal
POST /color-surveys
오류가 발생했습니다.
400
Invalid Color Code
```

- `colorCode` 누락으로 **400**과 메시지 **`Invalid Color Code`** 가 반환됩니다.

## 6) 네트워크 실패 등: `error.response` 존재 여부 확인

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

...
// POST /color-surveys
console.log('POST /color-surveys');
const surveyData = {
  mbti: 'ISFP',
  password: '0000',
};

try {
  const newColorSurvey = await createColorSurvey(surveyData);

  console.log(newColorSurvey);
} catch (error) {
  console.log('오류가 발생했습니다.');
  if (error.response) {
    console.log(error.response.status);
    console.log(error.response.data);
  } else {
    console.log('Failed request');
  }
}
```

**실행 예**

```terminal
POST /color-surveys
오류가 발생했습니다.
Failed request
```

- **응답이 도착하지 않은 경우**(`DNS 에러`, `네트워크 단절` 등)에는 `error.response`가 **없습니다**.
  → 안전하게 **존재 여부를 먼저 체크**합니다.
