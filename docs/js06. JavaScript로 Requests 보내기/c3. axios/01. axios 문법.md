# axios 문법

**정의**: **axios**는 `fetch`보다 간결한 문법과 편의 기능을 제공하는 **서드파티 HTTP 클라이언트**입니다.
**한 줄 요약**: `axios.get(url, { params })` / `axios.post(url, data)` 처럼 **간단한 호출**과 **자동 JSON 처리**가 장점입니다.

---

## 1) 설치

```terminal
npm install axios
```

## 2) (변경 전) 예시: `fetch` 기반 API 함수

```js
// src/js06-js-requests/ch3-axios/axiosApi.js

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const url = new URL('https://learn.codeit.kr/api/color-surveys');
  Object.keys(params).forEach((key) => {
    url.searchParams.append(key, params[key]);
  });

  const res = await fetch(url);
  const data = await res.json();

  return data;
}

// GET /api/color-surveys/:id
export async function getColorSurvey(id) {
  const res = await fetch(`https://learn.codeit.kr/api/color-surveys/${id}`);
  const data = await res.json();

  return data;
}

// POST /api/color-surveys
export async function createColorSurvey(surveyData) {
  const res = await fetch('https://learn.codeit.kr/api/color-surveys', {
    method: 'POST',
    headers: {
      'Content-type': 'application/json',
    },
    body: JSON.stringify(surveyData),
  });

  const data = await res.json();

  return data;
}
```

## 3) (변경 후) axios로 변환

### 단일 조회: `GET /api/color-surveys/:id`

```js
// src/js06-js-requests/ch3-axios/axiosApi.js
import axios from 'axios';

// GET /api/color-surveys/:id
export async function getColorSurvey(id) {
  const res = await axios.get(`https://learn.codeit.kr/api/color-surveys/${id}`);
  return res.data; // axios는 본문을 res.data로 제공
}
```

### 목록 조회 + 쿼리: `GET /api/color-surveys?offset=&limit=&...`

```js
// src/js06-js-requests/ch3-axios/axiosApi.js
import axios from 'axios';

// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const res = await axios.get('https://learn.codeit.kr/api/color-surveys', {
    params, // 객체를 넘기면 axios가 자동으로 query string 구성
  });
  return res.data;
}
```

> `null`/`undefined` 값은 쿼리스트링 생성 시 무시됩니다.

### 생성: `POST /api/color-surveys`

```js
// src/js06-js-requests/ch3-axios/axiosApi.js
import axios from 'axios';

// POST /api/color-surveys
export async function createColorSurvey(surveyData) {
  // JS 객체를 그대로 전달하면 axios가 JSON으로 직렬화하고 헤더도 설정
  const res = await axios.post('https://learn.codeit.kr/api/color-surveys', surveyData);
  return res.data;
}
```

## 4) axios 인스턴스 사용(공통 옵션)

```js
// src/js06-js-requests/ch3-axios/axiosApi.js
import axios from 'axios';

const instance = axios.create({
  baseURL: 'https://learn.codeit.kr/api', // baseURL 키 철자 주의
  timeout: 3000,
});
```

### 인스턴스로 API 함수 재작성

```js
// GET /api/color-surveys
export async function getColorSurveys(params = {}) {
  const res = await instance.get('/color-surveys', { params });
  return res.data;
}

// GET /api/color-surveys/:id
export async function getColorSurvey(id) {
  const res = await instance.get(`/color-surveys/${id}`);
  return res.data;
}

// POST /api/color-surveys
export async function createColorSurvey(surveyData) {
  const res = await instance.post('/color-surveys', surveyData);
  return res.data;
}
```

> 이제 **공통 URL/타임아웃**은 인스턴스 한 곳에서 관리합니다.

## 5) 동작 테스트 (`main.js`)

```js
// src/js06-js-requests/ch3-axios/main.js
import { getColorSurveys, getColorSurvey, createColorSurvey } from './axiosApi.js';

// GET /color-surveys
console.log('GET /color-surveys');
const surveys = await getColorSurveys({ offset: 10, limit: 5 });
console.log(surveys);

// GET /color-surveys/:id
console.log('GET /color-surveys/:id');
const survey = await getColorSurvey(32);
console.log(survey);

// POST /color-surveys
console.log('POST /color-surveys');
const surveyData = {
  mbti: 'ISFP',
  colorCode: '#123456',
  password: '0000',
};
const newColorSurvey = await createColorSurvey(surveyData);
console.log(newColorSurvey);
```

**실행 예**

- 목록: `count/next/previous/results` 구조
- 단일: `{ createdAt, updatedAt, colorCode, id, mbti }`
- 생성: 새 객체 반환

## 6) method-argument 요약

- **GET/DELETE**: 두 번째 인자에 **옵션** (`{ params, headers, timeout, ... }`)
- **POST/PATCH/PUT**: **두 번째 인자 데이터(body)**, **세 번째 인자 옵션**
- 옵션에는 **헤더/쿼리/타임아웃 등**을 설정할 수 있습니다.
- 자세한 옵션 DOCS: [Request Config | Axios Docs](https://axios-http.com/kr/docs/req_config)
