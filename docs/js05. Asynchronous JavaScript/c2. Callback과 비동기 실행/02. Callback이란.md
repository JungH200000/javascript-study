# Callback(콜백)

**정의(한 줄 요약)**
콜백은 **함수의 argument(인자)로 다른 함수를 전달**하는 방식이며, 전달된 그 함수를 **콜백 함수**라고 한다.

---

## 1) 기본 예시: 함수 자체를 전달하기

### 코드

```js
function sayHello() {
  console.log('Hello World!');
}

function sayGoodbye() {
  console.log('Goodbye World!');
}

function printMessage(func) {
  // 특정 함수를 파라미터로 받아서 호출하는 함수
  console.log('Printing message...');
  func();
}

printMessage(sayHello);
// Printing message...
// Hello World!
```

### 포인트 & 라인별 설명

- `function sayHello() { ... }` / `function sayGoodbye() { ... }`
  콘솔에 문자열을 출력하는 **일반 함수 정의**입니다.
- `function printMessage(func) { ... }`
  **함수를 파라미터로 받는 함수**입니다. 내부에서 `func()`로 **전달된 함수를 실행**합니다.
- `printMessage(sayHello);`
  **괄호 없이 함수 이름만** 넘깁니다. → **호출이 아니라 “참조를 전달”** 하는 것입니다.
  그 결과, `printMessage` 내부에서 `func()`가 실행되어 `Hello World!`가 출력됩니다.

> 주의: `printMessage(sayHello())`처럼 괄호를 붙이면 **즉시 호출**이 되어 **전달이 아니라 실행 결과를 넘기는** 것이 됩니다.

### 간단한 콜백을 화살표 함수로 전달하기

```js
//...

// sayHello 함수를 arrow function으로
printMessage(() => console.log('Hello World!'));
```

- 호출 시점에 **간단한 동작을 즉석에서 정의**할 때 유용합니다. (간단한 콜백에 화살표 함수를 사용할 수도 있음)

---

## 2) 파라미터를 받는 콜백

### 코드

```js
function sayHello(name) {
  console.log(`Hello ${name}!`);
}

function sayGoodbye(name) {
  console.log(`Goodbye ${name}!`);
}

function printMessage(func, name) {
  // 특정 함수를 파라미터로 받아서 호출하는 함수
  console.log('Printing message...');
  func(name);
}

printMessage(sayHello, 'Chung');
// Printing message...
// Hello Chung!
```

### 포인트 & 라인별 설명

- `sayHello(name)` / `sayGoodbye(name)`
  **이름을 받아** 인사 문구를 출력합니다.
- `printMessage(func, name)`
  **콜백 함수와 값(이름)을 함께** 받습니다. 내부에서 `func(name)`으로 **콜백에 인자를 전달**해 실행합니다.
- `printMessage(sayHello, 'Chung')`
  이 호출에서는 `func` ← `sayHello`, `name` ← `'Chung'`이 매핑됩니다.
  결과: `Hello Chung!`

### 화살표 함수로도 동일하게 가능

```js
//...

printMessage((name) => {
  console.log(`Goodbye ${name}`);
}, 'JiOne');
// Printing message...
// Goodbye JiOne
```

- **콜백이 파라미터를 받는 경우**에도 화살표 함수로 **즉석 정의**해 전달할 수 있습니다.

---

## 핵심 요약

- **콜백**: 함수의 **인자로 다른 함수를 전달**하는 패턴이며, 전달된 함수가 **콜백 함수**입니다.
- 함수 **참조를 전달**하려면 **괄호 없이** 넘깁니다. (예: `printMessage(sayHello)`)
- 콜백은 **파라미터를 받을 수도** 있으며, 바깥 함수에서 **값을 채워 실행**합니다.
- **간단한 콜백**은 **화살표 함수**로 **즉석에서 정의**해 전달할 수 있습니다.
