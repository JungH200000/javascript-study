# 비동기 함수의 예시들

**정의(한 줄 요약)**

- **비동기 함수**: 지금 당장 끝내지 않고, **나중에 콜백을 실행하도록 예약**하는 함수.
- **콜백(callback)**: **나중에 실행하기 위해** 다른 함수의 **인자**로 전달되는 함수.

아래 예시들을 기반으로, **동작 흐름**과 **콜백이 실행되는 시점**에 초점을 맞춰 정리합니다.

---

## 1) `setTimeout()` 함수

앞에서 다룬 `setTimeout()`입니다.

```js
// ...

setTimeout(callback, delay);

// ...
```

### 동작 순서

1. `setTimeout()` **이전**에 있는 코드 실행
2. `setTimeout()` 실행: **delay만큼 기다리는 타이머 시작**
3. `setTimeout()` **이후**에 있는 코드 실행
4. **delay가 지나면** `callback` 실행

---

## 2) 임의의 비동기 함수 형태

역할은 달라도 **사용 패턴**은 비슷합니다.

```js
// ...

asyncFunction(callback, ...);

// ...
```

### 동작 순서

1. `asyncFunction()` **이전** 코드 실행
2. `asyncFunction()` 실행: **특정 조건**이 만족되면(예: 시간이 지남, 이벤트 발생) `callback`이 실행되도록 등록
3. `asyncFunction()` **이후** 코드 실행
4. **조건이 만족되는 시점에** `callback` 실행

> 이 흐름을 이해하면 다양한 비동기 함수를 더 쉽게 사용할 수 있습니다.

---

## 3) `setInterval()` 함수

**시간 간격**을 두고 콜백을 **반복 실행**합니다.

```js
console.log('Start');

// setInterval(callback, interval): interval 단위는 밀리초입니다.
setInterval(() => console.log('2초가 지났습니다'), 2000);

console.log('End');
```

```terminal
Start
End
2초가 지났습니다
2초가 지났습니다
2초가 지났습니다
2초가 지났습니다
...
```

> 콜백은 **interval이 지난 후 처음으로 실행**됩니다.

### 반복 멈추기 (`clearInterval` 사용)

```js
console.log('Start');

const intervalID = setInterval(() => console.log('2초가 지났습니다'), 2000);

// 7초 후에 setInterval() 해제
setTimeout(() => clearInterval(intervalID), 7000);

console.log('End');
```

```terminal
start
End
2초가 지났습니다.
2초가 지났습니다.
2초가 지났습니다.
```

> 2초마다 출력되지만 **7초 후 해제**하므로 총 **세 번**만 출력됩니다.

---

## 4) DOM의 `addEventListener()` 함수

웹 요소에 **상호 작용이 있을 때 실행할 콜백**을 등록합니다.

```js
const btn = document.querySelector('.my-btn');

btn.addEventListener('click', () => console.log('button clicked!'));

// ...
```

- 첫 줄: `.my-btn` 클래스를 가진 요소를 찾아 `btn`에 저장.
- 둘째 줄: `btn`에 **클릭 이벤트**가 발생하면 콜백(`() => console.log(...)`) 실행.
- 결과적으로, 아래 코드가 계속 실행되다가 **사용자가 버튼을 클릭하는 순간** 콜백이 실행되어 콘솔에 메시지가 찍힙니다.

---

## 5) React의 `useEffect()` 함수

```jsx
function PostList() {
  // ...

  useEffect(() => console.log('render finished!'), []);

  return (
    <div className="post-list">
      <div className="post-item">...</div>
      <div className="post-item">...</div>
      <div className="post-item">...</div>
      ...
    </div>
  );
}
```

- `PostList()`는 화면의 **포스팅 목록 컴포넌트**입니다.
- `useEffect()`는 **컴포넌트가 화면에 그려지는 시점**에 콜백을 실행합니다.
- 즉, `PostList()`의 실행과 **화면 렌더링 작업이 끝난 뒤**, `render finished!`가 출력됩니다.
- 실제로는 이 시점에 **데이터 요청 등 다양한 작업**을 수행하기도 합니다.

---

## 6) Express의 `get()` 함수

```js
app.get('/hello', (req, res) => {
  res.send('Success!');
});

// ...
```

- 서버는 **요청이 언제 들어올지 모르는** 특성상 처리를 **비동기 형태**로 합니다.
- `app.get()`은 `/hello` 경로로 **GET 요청**이 들어오면 **두 번째 인자인 콜백**을 실행합니다.
- 이 콜백은 요청 객체(`req`)와 응답 객체(`res`)를 받아, **적절한 응답**을 보냅니다(예: `'Success!'`).

---

## 핵심 요약

- **비동기 함수**는 지금 끝내지 않고, **나중에 콜백을 실행**하도록 예약합니다.
- `setTimeout(callback, delay)`는 **delay 후** 콜백을 실행하고, `setInterval`은 **간격마다 반복 실행**합니다.
- `addEventListener`는 **이벤트 발생 시점**에 콜백을 실행합니다.
- `useEffect`는 **컴포넌트가 화면에 그려진 뒤** 콜백을 실행합니다.
- Express의 `app.get`은 **요청이 들어올 때** 등록한 콜백으로 응답을 보냅니다.
