# Parameter vs Argument

**정의(한 줄 요약)**

- **Parameter(파라미터)**: 함수 **선언부의 괄호** 안에서 값을 **받기 위해 쓰는 변수의 이름**.
- **Argument(아규먼트)**: 함수 **호출 시 괄호** 안으로 **실제로 전달하는 값**.

---

## 예시 코드

```js
function add(x, y) {
  // x, y: parameters (함수 선언부에서 값을 받는 변수)
  return x + y; // 두 값을 더해 반환
}

add(1, 2); // 1, 2: arguments (함수 호출 시 실제로 넘기는 값) → 3
```

### 라인별 설명

- `function add(x, y) {`

  - `x`, `y`는 **parameter**입니다. 함수가 호출될 때 전달될 값을 **이름으로 받는 자리**입니다.

- `return x + y;`

  - 받은 두 값을 더해 **반환**합니다.

- `add(1, 2);`

  - `1`, `2`는 **argument**입니다. 함수를 **실제로 호출**할 때 넘기는 **값**입니다. 결과는 `3`입니다.

---

## 정리 포인트

- **Parameter**는 “받는 쪽의 **이름**”, **Argument**는 “넘기는 **값**”입니다.
- 둘 다 괄호와 함께 보이지만, **선언의 괄호(파라미터)** 와 **호출의 괄호(아규먼트)** 처럼 **위치와 역할이 다릅니다**.

---

## 핵심 요약

- **Parameter**: 함수 **선언부**에서 값을 받는 **변수 이름**.
- **Argument**: 함수 **호출 시** 실제로 전달되는 **값**.
- 예시에서 `x, y`는 parameter, `1, 2`는 argument입니다.
- 초심자 관점에서는 위처럼 간단히 구분만 하고 넘어가도 충분합니다.
