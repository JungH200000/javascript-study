# Callback Hell

**정의(한 줄 요약)**

- **콜백(Callback)**: **나중에 실행**하기 위해 **다른 함수의 인자**로 전달된 함수.
- **Callback Hell**: **여러 비동기 작업을 연속**으로 처리하려다 **콜백이 중첩**되어 코드가 **읽기/디버깅/테스트**하기 어려워지는 상황.

---

## 준비: `functions.js` (세 함수 모두 비동기)

```js
export function getEmployees(callback) {
  console.log('Sending request...');
  const response = `[{ "id": 1, "name": "Jason", "email": "jason@codeitmall.kr", "department": "engineering" }, { "id": 2, "name": "Alice", "email": "alice@codeitmall.kr", "department": "engineering" }, { "id": 3, "name": "Brian", "email": "brian@codeitmall.kr", "department": "marketing" }, { "id": 4, "name": "Erica", "email": "erica@codeitmall.kr", "department": "marketing" }, { "id": 5, "name": "Wilson", "email": "wilson@codeitmall.kr", "department": "sales" }]`;
  setTimeout(() => callback(response), 1000);
}

export function json(string, callback) {
  console.log('Parsing string...');
  const json = JSON.parse(string);
  setTimeout(() => callback(json), 1000);
}

export function groupEmployees(employees, callback) {
  console.log('Grouping employees...');
  const res = {};
  employees.forEach((employee) => {
    const { name, department } = employee;
    if (!(department in res)) {
      res[department] = [];
    }
    res[department].push(name);
  });
  setTimeout(() => callback(res), 1000);
}
```

**핵심 포인트**

- 세 함수 모두 `setTimeout(..., 1000)`을 사용해 **1초 뒤 콜백 실행**을 예약 → **비동기** 동작.
- `getEmployees`: **문자열 형태**의 응답을 콜백으로 전달.
- `json`: 문자열을 `JSON.parse`로 **배열/객체로 파싱** 후 콜백.
- `groupEmployees`: 직원 목록을 **부서별로 묶어** `{ department: [names...] }` 형태로 콜백.

---

## 모듈 가져오기

```js
import { getEmployees, json, groupEmployees } from './functions.js';
```

> **세 함수 모두 비동기**이므로, 호출 후 **아래 코드가 먼저 진행**될 수 있습니다.

---

## 1) `getEmployees` 사용

```js
import { getEmployees, json, groupEmployees } from './functions.js';

getEmployees((response) => console.log(response));
```

```terminal
Sending request...
[{ "id": 1, "name": "Jason", "email": "jason@codeitmall.kr", "department": "engineering" }, { "id": 2, "name": "Alice", "email": "alice@codeitmall.kr", "department": "engineering" }, { "id": 3, "name": "Brian", "email": "brian@codeitmall.kr", "department": "marketing" }, { "id": 4, "name": "Erica", "email": "erica@codeitmall.kr", "department": "marketing" }, { "id": 5, "name": "Wilson", "email": "wilson@codeitmall.kr", "department": "sales" }]
```

- 응답은 **문자열**이므로, **파싱**이 필요합니다.

---

## 2) `json`으로 파싱

```js
import { getEmployees, json, groupEmployees } from './functions.js';

json(
  '[{ "id": 1, "name": "Jason", "email": "jason@codeitmall.kr", "department": "engineering" }, { "id": 2, "name": "Alice", "email": "alice@codeitmall.kr", "department": "engineering" }, { "id": 3, "name": "Brian", "email": "brian@codeitmall.kr", "department": "marketing" }, { "id": 4, "name": "Erica", "email": "erica@codeitmall.kr", "department": "marketing" }, { "id": 5, "name": "Wilson", "email": "wilson@codeitmall.kr", "department": "sales" }]',
  (data) => console.log(data)
);
```

```terminal
Parsing string...
[
  { id: 1, name: 'Jason', email: 'jason@codeitmall.kr', department: 'engineering' },
  { id: 2, name: 'Alice', email: 'alice@codeitmall.kr', department: 'engineering' },
  { id: 3, name: 'Brian', email: 'brian@codeitmall.kr', department: 'marketing' },
  { id: 4, name: 'Erica', email: 'erica@codeitmall.kr', department: 'marketing' },
  { id: 5, name: 'Wilson', email: 'wilson@codeitmall.kr', department: 'sales' }
]
```

- 첫 번째 인자: **파싱할 문자열**.
- 두 번째 인자: **파싱 완료 후 실행할 콜백**(파싱 결과를 인자로 받음).

---

## 3) `groupEmployees`로 부서별 묶기

```js
import { getEmployees, json, groupEmployees } from './functions.js';

groupEmployees(
  [
    { id: 1, name: 'Jason', email: 'jason@codeitmall.kr', department: 'engineering' },
    { id: 2, name: 'Alice', email: 'alice@codeitmall.kr', department: 'engineering' },
    { id: 3, name: 'Brian', email: 'brian@codeitmall.kr', department: 'marketing' },
    { id: 4, name: 'Erica', email: 'erica@codeitmall.kr', department: 'marketing' },
    { id: 5, name: 'Wilson', email: 'wilson@codeitmall.kr', department: 'sales' },
  ],
  (results) => console.log(results)
);
```

```terminal
Grouping employees...
{
  engineering: [ 'Jason', 'Alice' ],
  marketing: [ 'Brian', 'Erica' ],
  sales: [ 'Wilson' ]
}
```

- 첫 번째 인자: **직원 배열**.
- 두 번째 인자: **처리 완료 후 실행할 콜백**(결과 객체를 인자로 받음).

---

## 4) 비동기 작업을 **연속**으로 처리하면?

```js
import { getEmployees, json, groupEmployees } from './functions.js';

getEmployees((response) => {
  json(response, (data) => {
    groupEmployees(data, (results) => {
      console.log(results);
    });
  });
});
```

```terminal
Sending request...
Parsing string...
Grouping employees...
{
  engineering: [ 'Jason', 'Alice' ],
  marketing: [ 'Brian', 'Erica' ],
  sales: [ 'Wilson' ]
}
```

**해석**

- **응답 수신** → 그 **문자열을 파싱** → **부서별로 그룹화** → **최종 결과 출력**.
- 그러나 콜백이 **안쪽으로 계속 중첩**되어 **가독성/디버깅/테스트가 어려워짐** → 이것이 **Callback Hell**.

> 이 문제를 해결하기 위해 **`Promise` 문법이 2015년(ES2015)** 에 등장했다.

---

## 핵심 요약

- 세 함수(`getEmployees`/`json`/`groupEmployees`)는 **모두 비동기**로, **콜백을 인자**로 받아 **작업 완료 시 실행**합니다.
- 실제 사용에서는 **이전 단계의 결과를 다음 단계의 입력**으로 넘기게 되고, **콜백 중첩**이 발생합니다.
- 이 **중첩 구조** 때문에 코드가 **읽기/디버깅/테스트**하기 어려워지는 상황을 **Callback Hell**이라 합니다.
