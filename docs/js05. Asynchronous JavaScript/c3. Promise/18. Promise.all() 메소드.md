# `Promise.all()` 메소드

**정의(한 줄 요약)**

- **`Promise.all(iterable)`**: 여러 **Promise가 모두 Fulfilled** 되기를 **동시에 기다렸다가**, **각 성공 값의 배열**을 새 Promise로 반환한다(하나라도 Rejected면 **즉시 Rejected**).

---

## 왜 필요한가?

여러 비동기 작업을 **병렬로 보내고**, **모든 결과가 모인 뒤 한 번에 사용**하고 싶을 때 유용합니다. `await`을 루프 안에서 **매번** 쓰면 **순차 대기**가 되어 비효율적입니다.

---

## 예제 1: 개별 요청을 바로바로 출력

```js
// main.js
async function printEmployees(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  console.log(data);
}

for (let i = 1; i < 11; i++) {
  printEmployees(i);
}
```

- 각 `printEmployees` 호출은 **자기 내부에서** `await`하며 출력까지 처리합니다.
- **즉시 출력**하는 목적에는 적합하지만, **모든 결과를 모아 한꺼번에 쓰기**에는 불편합니다.

---

## 예제 2: 값을 함수 바깥에서 받으려는 시도(순차 대기 발생)

```js
// main.js
async function getEmployees(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  return data;
}

for (let i = 1; i < 11; i++) {
  const employee = await getEmployees(i);
}
```

- `await`이 루프 안에 있으므로 **요청 → 대기 → 다음 요청**으로 **순차 실행**됩니다.
- 결과적으로 **전체 시간**이 오래 걸립니다.

---

## 예제 3: `Promise.all`로 병렬 처리 준비(배열에 약속 모으기)

```js
// main.js
async function getEmployees(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  return data;
}

const promises = [];

for (let i = 1; i < 11; i++) {
  promises.push(getEmployees(i));
}

Promise.all(promises);
```

- 루프에서는 **`await`을 하지 않고** `Promise`만 **모읍니다.**
- 이 시점에 **요청들이 거의 동시에 발사**되고, `promises`에는 **Pending 중인 Promise**들이 들어갑니다.
- `Promise.all(promises)`는 **새 Promise**를 반환합니다(아직 대기 중).

---

## 예제 4: 모두 끝나면 한 번에 받기(`await Promise.all`)

```js
// main.js
async function getEmployees(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  return data;
}

const promises = [];

for (let i = 1; i < 11; i++) {
  promises.push(getEmployees(i));
}

const employees = await Promise.all(promises);
console.log(employees);
```

- **모든 Promise가 Fulfilled** 되면 `employees`에는 **각 요청의 성공 값**이 **배열**로 담깁니다.
- 하나라도 **Rejected**면 `Promise.all`의 Promise가 **Rejected**가 됩니다(오류는 그 **거부 이유**).

---

## 예제 5: `try...catch`로 오류 처리

```js
// main.js
async function getEmployees(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  return data;
}

const promises = [];

for (let i = 1; i < 11; i++) {
  promises.push(getEmployees(i));
}

let employees;

try {
  employees = await Promise.all(promises);
} catch {
  console.log('Error!');
}

console.log(employees);
```

- `employees`를 **바깥에 선언**해 두면, `try...catch` 이후에도 접근할 수 있습니다.
- `Promise.all`에서 **어느 하나라도 실패**하면 `catch`가 실행됩니다.

---

## 동작 핵심 정리

- **배열에 Promise를 모은 뒤** `Promise.all([...])`로 **동시에 대기**한다.
- **모든** Promise가 **성공**하면 **성공 값의 배열**로 **Fulfilled**.
- **하나라도 실패**하면 **즉시 Rejected**가 되어 **그 오류**를 가진다.
- `await` 또는 `then`으로 `Promise.all`의 **결과**를 사용할 수 있다.
