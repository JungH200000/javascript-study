# Promise와 오류 제대로 이해하기

**정의(한 줄 요약)**

- **Promise**: 비동기 작업의 **상태와 결과**를 담는 객체(Pending / Fulfilled / Rejected).
- **`await`**: Promise가 **Fulfilled/Rejected가 될 때까지 대기**하고, 성공 값은 **반환**, 실패 값은 **throw**한다.
- **`try…catch…finally`**: 비동기 코드에서 **오류를 잡아(catch)** 처리하고, **항상 마지막에 실행**할 로직은 `finally`에 둔다.

---

## 예제 코드

```js
export async function printEmployees() {
  try {
    const response = await fetch('https://learn.codeit.krError/api/employees');
    const data = await response.json();

    console.log(data);
  } catch (error) {
    console.log('Error!');
    return;
  } finally {
    console.log('Finished');
  }
}
```

### 코드 포인트

- `fetch(...)` → **Promise 반환**.
- `await fetch(...)`에서 **오류**가 생기면, 해당 Promise가 **Rejected**가 되고 **오류가 결괏값**이 된다.
- 이때 `await`은 그 **오류 값을 throw** 하므로, `try` 블록을 **탈출**해 `catch`가 실행된다.
- `return`으로 빠져도 `finally`는 **무조건 마지막에 실행**된다.

---

## 실행 흐름

### `main.js`

```js
import { printEmployees } from './asyncFunctions.js';

printEmployees();

console.log('Task 2');
console.log('Task 3');
```

### `asyncFunction.js`

```js
export async function printEmployees() {
  try {
    const response = await fetch('https://learn.codeit.krError/api/employees');
    const data = await response.json();

    console.log(data);
  } catch (error) {
    console.log('Error!');
    return;
  } finally {
    console.log('Finished');
  }
}
```

### 단계별 흐름 정리

1. `main.js` 실행 → `printEmployees` **import**.
2. `printEmployees();` 호출 → 함수 내부에서 `fetch(...)` 실행(**Promise 생성**).
3. `await`을 만나면 **결과 대기 중** 함수 바깥으로 나와, 아래 코드(`Task 2`, `Task 3`)를 **먼저 실행**.

   ```terminal
   Task 2
   Task 3
   ```

4. 비동기 작업은 **성공(Fulfilled)** 또는 **실패(Rejected)** 로 끝난다.

   - **성공 시**: `await`이 **성공 값을 반환** → 다음 줄(`response.json()`)로 진행.
   - **실패 시**: `await`이 **오류를 throw** → `catch`로 이동하여 `'Error!'` 출력.

5. `catch`에서 `return` 하더라도, `finally`는 **항상 실행**되어 `'Finished'` 출력.
6. 전체적으로, **`await`이 값을 반환(성공)하거나 오류를 throw(실패)** 하도록 만들어져 있어, 익숙한 **동기적 코드 형태**로 비동기 흐름을 다룰 수 있다.
