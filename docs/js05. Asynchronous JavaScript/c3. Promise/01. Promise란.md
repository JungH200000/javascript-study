# Promise란?

**정의(한 줄 요약)**

- **Promise**: 비동기 작업이 **끝난 뒤 값을 알려주겠다고 ‘약속’**하는 **객체**.

웹 요청을 보낼 때 자주 쓰는 `fetch`는 **Promise를 반환**합니다. 예시처럼 확인해 봅시다.

```js
const response = fetch('https://learn.codeit.kr/api/employees');
console.log(response);
```

```terminal
Promise { <pending> }
```

- `fetch(...)` 호출 즉시 **결괏값이 아직 준비되지 않았기 때문에** `Promise { <pending> }`가 출력됩니다.
- 의미: **나중에 작업이 끝나면** 이 Promise **안에 값이 채워진다**는 약속.

---

## 왜 Promise가 직관적인가 (흐름 비교)

**콜백 기반 코드**와 **Promise 기반 코드**를 나란히 보여 줍니다.

### 콜백 기반

```js
getEmployees((response) => {
  json(response, (data) => {
    console.log(data);
  });
});
```

### Promise 기반

```js
const response = await fetch('...');
const data = await response.json();

console.log(data);
```

- 위처럼 **위→아래로 읽히는 익숙한 형태**로 작성할 수 있어 **가독성이 좋다**는 점이 강조됩니다.
- 핵심: **비동기 처리도 평소 쓰던 코드 흐름처럼**(값을 변수에 담고 다음 줄에서 사용) 표현할 수 있습니다.

---

## Promise를 다루는 두 가지 방법

1. `async` / `await` 문법
2. `.then()` 메소드 + 콜백

> 두 방식 모두 **자주 사용**되므로 **둘 다 알아두는 것**이 좋다는 취지입니다.

---

## 핵심 요약

- `fetch`는 **Promise를 반환**하며, **작업이 끝난 뒤** 값을 제공합니다.
- Promise는 **비동기 결과를 나중에 전달**하는 **객체**입니다.
- 콜백 중첩 대신 **`await`를 이용해 직관적인 순서**로 코드를 작성할 수 있습니다.
- Promise 사용법은 **`async/await`** 와 **`.then()` 콜백** 두 가지가 있습니다.
