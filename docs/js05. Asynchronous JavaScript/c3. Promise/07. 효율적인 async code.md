# 효율적인 async 코드

**정의(한 줄 요약)**

- **효율적인 async 코드**: `async`/`await`의 **대기 지점**을 잘 배치해, **불필요한 순차 대기**를 줄이고 **동시에 여러 비동기 작업**을 진행하도록 작성한 코드.

---

## 1) 순차 대기: `for`문 안에서 매번 `await`

```js
async function printEmployees() {
  for (let i = 1; i < 11; i++) {
    const response = await fetch(`https://learn.codeit.kr/api/employees/${i}`);
    const data = await response.json();

    console.log(data);
  }
}

printEmployees();
```

### 실행 예

```terminal
{
  id: 1,
  name: 'Jason',
  email: 'jason@codeitmall.kr',
  department: 'engineering'
}
{
  id: 2,
  name: 'Alice',
  email: 'alice@codeitmall.kr',
  department: 'engineering'
}
...
{
  id: 10,
  name: 'Alex',
  email: 'alex@codeitmall.kr',
  department: 'sales'
}
```

**포인트**

- 각 반복에서 `fetch → json()`을 **순서대로 기다립니다.**
- 즉, **1번이 끝난 뒤 2번**, … **10번까지 차례차례** 진행되어 **총 대기시간이 누적**됩니다.

### for문을 풀어 쓰면 이런 형태

> 동일 스코프에서 `const` 재선언 문제가 생기지 않도록 **블록 스코프**로 감쌌습니다.

```js
async function printEmployees() {
  {
    const response = await fetch(`https://learn.codeit.kr/api/employees/1`);
    const data = await response.json();
    console.log(data);
  }
  {
    const response = await fetch(`https://learn.codeit.kr/api/employees/2`);
    const data = await response.json();
    console.log(data);
  }
  // ...
}

printEmployees();
```

- 의미상 **첫 번째 요청을 다 기다린 뒤** 두 번째 요청을 보냅니다 → **비효율적**.

---

## 2) 동시에 시작: `async` 함수를 여러 번 호출

같은 작업을 **동시에** 시작하도록 바꿔 봅니다.

```js
async function printEmployee(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  console.log(data);
}

for (let i = 1; i < 11; i++) {
  printEmployee(i); // ❗ 여기서 기다리지 않고 1~10번을 연속 호출
}
```

**포인트**

- `printEmployee(1)`에서 **대기하는 동안** 함수 바깥으로 빠져나와 **바로 `printEmployee(2)`** 를 호출합니다.
- 이런 식으로 **1~10 요청을 거의 동시에** 보냅니다 → **총 소요시간 단축**.
- 비교 시간: **순차 2.824s → 동시 0.793s**.
- 단, **응답 도착 순서가 뒤죽박죽**일 수 있습니다(요청 순서 보장 없음).

### 동시에 여러 요청을 보낸 흐름

```js
async function printEmployee(id) {
  const response = await fetch(`https://learn.codeit.kr/api/employees/${id}`);
  const data = await response.json();

  console.log(data);
}

printEmployee(1);
printEmployee(2);
printEmployee(3);
// ...
```

- 각 호출이 **자체적으로 비동기**로 진행되며, **응답이 오는 즉시** 해당 콜백 흐름이 이어집니다.
- **작업 완료 순서가 중요하지 않다면** 이 방식이 **더 효율적**입니다.
