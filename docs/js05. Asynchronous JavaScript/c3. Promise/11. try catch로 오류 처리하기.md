# try … catch로 오류 처리하기

**정의(한 줄 요약)**

- **`try … catch`**: 비동기 작업 중 **오류가 발생해도 프로그램이 계속 진행**되도록, 오류를 **잡아(catch) 처리**하는 문법.
- **`finally`**: `try … catch`의 결과와 **무관하게 항상 마지막에 실행**되는 블록.

비동기 작업(예: `fetch`)은 네트워크 문제, 잘못된 URL 등으로 **실패**할 수 있습니다. 아래 예시를 통해 **오류가 날 때 흐름**과 **안전하게 감싸는 방법**을 살펴봅니다.

---

## 1) 기본 형태: 정상 응답일 때의 흐름

```js
export async function printEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees'); // 비동기 요청
  const data = await response.json(); // 응답 본문 파싱

  console.log(data); // 직원 데이터 출력
  console.log('Finished'); // 실행 완료 표시
}
```

- `fetch`와 `response.json()`은 **시간이 걸릴 수 있어** `await`으로 **작업 완료**를 기다립니다.
- 정상일 때는 **데이터**와 **'Finished'** 가 차례로 출력됩니다. (정상 종료)

---

## 2) 실패 유도: 잘못된 URL로 요청하면?

```js
export async function printEmployees() {
  const response = await fetch('https://learn.codeit.krError/api/employees'); // 의도적으로 잘못된 URL
  const data = await response.json();

  console.log(data);
  console.log('Finished');
}
```

- 잘못된 주소로 인해 `fetch`에서 **오류**가 발생합니다.
- 이 경우 `console.log('Finished')`까지 **도달하지 못하고** 프로그램이 오류로 종료됩니다.

---

## 3) `try … catch`로 안전하게 감싸기

```js
export async function printEmployees() {
  try {
    const response = await fetch('https://learn.codeit.krError/api/employees'); // 여기서 오류 발생 가능
    const data = await response.json();

    console.log(data); // 정상 시 데이터 출력
  } catch (error) {
    console.log('Error: ', error); // 오류 객체를 받아 출력(간단 처리)
  }

  console.log('Finished'); // 오류가 나도 여기까지 진행됨
}
```

### 흐름 설명

- **오류 없음**: `try` 블록을 끝까지 실행 → 바깥의 `'Finished'` 출력.
- **오류 발생**: 그 **지점에서 즉시 `catch`로 이동** → 오류 메시지 출력 → 바깥의 `'Finished'` 출력.
- 결과적으로, **프로그램이 중단되지 않고** 끝까지 진행됩니다.

> `catch`에서 받은 `error` 객체를 활용해 **조금 더 세밀한 처리**도 가능합니다.

---

## 4) `catch`에서 즉시 종료하고 싶을 때 + `finally`의 용도

### `catch`에서 종료(`return`)하면 바깥 코드는 실행되지 않음

```js
export async function printEmployees() {
  try {
    const response = await fetch('https://learn.codeit.krError/api/employees');
    const data = await response.json();

    console.log(data);
  } catch (error) {
    console.log('Error!');
    return; // 여기서 함수 종료 → 아래 'Finished'는 실행되지 않음
  }

  console.log('Finished');
}
```

### 항상 마지막에 실행할 코드가 있다면 `finally`

```js
export async function printEmployees() {
  try {
    const response = await fetch('https://learn.codeit.krError/api/employees');
    const data = await response.json();

    console.log(data);
  } catch (error) {
    console.log('Error!');
    return; // 함수 종료를 시도하더라도…
  } finally {
    console.log('Finished'); // …항상 실행됨
  }
}
```

- `try`가 **정상**이어도, `catch`가 **실행**되어도, 심지어 `catch`에서 `return`을 해도 **`finally`는 반드시 실행**됩니다.
- 따라서, **무조건 마지막에 실행해야 하는 코드**는 `finally`에 두면 됩니다.
