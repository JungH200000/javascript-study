# then() 메소드

**정의(한 줄 요약)**

- **`then()`**: 앞선 **Promise가 완료되면** 등록한 **콜백을 실행**하고, **새로운 Promise를 반환**하는 메소드.
- **Promise chain**: `then`을 **연속으로 이어** 비동기 단계를 순서대로 표현하는 방식.

---

## 1) 기존 `async/await` 코드

```js
// main.js
async function printEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees'); // ① 요청
  const data = await response.json(); // ② JSON 파싱

  console.log(data); // ③ 결과 사용
}
```

- `fetch`와 `response.json()`은 **Promise**를 반환하고, `await`은 **완료까지 대기 후 값**을 줍니다.

---

## 2) `then` 문법으로 바꾸기

```js
const dataPromise = fetch('https://learn.codeit.kr/api/employees') // A. 요청(Promise)
  .then((response) => response.json()); // B. 완료 시 JSON 파싱(Promise)

// console.log(dataPromise); // Promise { <pending> }  ← 아직 대기(Pending)

dataPromise.then((data) => console.log(data)); // C. 파싱 완료 시 결과 사용
```

- `fetch`는 **Promise 반환** → 이어서 `then` 사용 가능.
- **`then` 자체도 Promise를 반환**하므로, 그 뒤에 **다시 `then`**을 붙일 수 있습니다.

---

## 3) Chaining

```js
fetch('https://learn.codeit.kr/api/employees') // ① 요청(Promise 반환)
  .then((response) => response.json()) // ② 응답 완료 → JSON 파싱(Promise 반환)
  .then((data) => console.log(data)); // ③ 파싱 완료 → 데이터 출력
```

- 이렇게 **연결해 쓰는 것**을 **Promise chain**이라고 합니다.

---

## 4) 동작 원리

다음 코드를 기준으로 설명합니다.

```js
fetch('https://learn.codeit.kr/api/employees')
  .then((response) => response.json())
  .then((data) => console.log(data));
```

1. `fetch(...)`는 **곧바로 Promise를 반환**합니다.
2. 이어지는 `then`들도 **즉시 새로운(대기 중인) Promise**를 반환합니다(콜백은 아직 실행 안 됨).
3. 요청이 완료되면 첫 번째 Promise가 **Fulfilled**가 됩니다.
4. 그러면 첫 번째 `then`의 **콜백**이 실행됩니다.
5. 이때 **앞 Promise의 결괏값**(응답 객체 `response`)이 콜백의 **첫 번째 인자**로 전달됩니다.
6. **콜백이 Promise를 반환**하면, 그 `then`이 반환한 Promise도 **그 Promise의 상태/결과를 그대로 따릅니다**.
7. **콜백이 일반 값**을 반환하면, 그 `then`이 반환한 Promise는 **Fulfilled**가 되고 **그 값**을 결과로 가집니다.

   - 위 코드에서는 `response.json()`을 반환하므로, **JSON 파싱이 끝나야** 다음 단계가 진행됩니다.

8. 파싱이 끝나면 다음 `then`의 콜백이 실행되고, **파싱 결과 `data`**가 인자로 전달됩니다.
9. `console.log(data)`는 `undefined`를 반환하므로, 마지막 Promise는 **Fulfilled(결과: `undefined`)**가 됩니다.
10. 마지막 Promise에 **이어지는 작업이 없다면** 추가로 신경 쓰지 않아도 됩니다.

---

## 5) 다른 코드와의 실행 순서

```js
fetch('https://learn.codeit.kr/api/employees')
  .then((response) => response.json())
  .then((data) => console.log(data));

console.log('Task 2');
console.log('Task 3');
```

**실행 결과**

```terminal
Task 2
Task 3
[
  { id: 1, name: 'Jason',  email: 'jason@codeitmall.kr',  department: 'engineering' },
  ...
  { id: 10, name: 'Alex',  email: 'alex@codeitmall.kr',   department: 'sales' }
]
```

- `fetch`가 **Pending**인 동안, 아래의 **동기 코드(`Task 2`, `Task 3`)**가 먼저 실행됩니다.
- 요청이 완료되어 **Fulfilled**가 되면, 이어진 `then`의 콜백이 실행되어 **데이터**가 출력됩니다.
