# async 함수

**정의(한 줄 요약)**

- **`async` 함수**: 함수 본문에서 **`await`을 사용할 수 있게 해 주는 함수**.
- **`await`**: **Promise가 완료될 때까지 기다렸다가 결괏값을 돌려주는 키워드**.

---

## 1) 왜 함수 밖 `await`은 위→아래 순서로 “멈춰 보일까?”

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
const data = await response.json();

console.log(data);

console.log('Task 2');

console.log('Task 3');
```

### 실행 결과

```terminal
[
  {
    id: 1,
    name: 'Jason',
    email: 'jason@codeitmall.kr',
    department: 'engineering'
  },
  ...
  {
    id: 10,
    name: 'Alex',
    email: 'alex@codeitmall.kr',
    department: 'sales'
  }
]
Task 2
Task 3
```

- 위처럼 **파일 상단(모듈 최상위)에서 `await`** 을 쓰면, 그 줄에서 **비동기 작업이 끝날 때까지 대기**합니다.
- 그래서 **데이터 출력이 먼저** 나오고, 그 다음에 `Task 2`, `Task 3`이 이어집니다.
- **Promise + `await`을 제대로 활용**하려면 **함수(= `async` 함수)** 를 이용하는 것이 좋습니다.

> 참고: `await`은 **`async` 함수 안** 또는 **ES 모듈의 최상위**에서만 사용할 수 있습니다. 현재 디렉터리는 ES 모듈로 인식되도록 설정되어 있어 최상위 `await`이 가능했습니다. CommonJS로 인식되면 경고가 발생합니다.

---

## 2) `await`은 어디에서 쓸 수 있나?

- **`async` 함수 내부**
- **ES 모듈의 최상위**(`package.json`의 `"type": "module"` 설정으로 ESM으로 인식)

함수 밖 최상위에서 `await`을 쓰지 않는 편이 일반적이므로, **보편적으로는 `async` 함수 안에서 사용**한다고 이해하면 좋습니다.

---

## 3) `async` 함수 만들기

### 함수 선언문 형태

```js
export async function printEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees');
  const data = await response.json();

  console.log(data);
}
```

### 화살표 함수 형태(오타 수정 반영)

```js
const printEmployeesArrow = async () => {
  const response = await fetch('https://learn.codeit.kr/api/employees');
  const data = await response.json();

  console.log(data);
};
```

- **`async` 키워드**를 붙이면, 본문에서 **`await` 사용 가능**해집니다.
- `await`은 **앞의 Promise가 Fulfilled/Rejected 상태가 될 때까지 대기**한 뒤, **성공 시 결괏값**을 돌려줍니다.

---

## 4) `async` 함수로 감쌌을 때의 실행 흐름

`main.js`:

```js
import { printEmployees } from './asyncFunctions.js';

printEmployees();

console.log('Task 2');
console.log('Task 3');
```

### 실행 결과

```terminal
Task 2
Task 3
[
  {
    id: 1,
    name: 'Jason',
    email: 'jason@codeitmall.kr',
    department: 'engineering'
  },
  ...
  {
    id: 10,
    name: 'Alex',
    email: 'alex@codeitmall.kr',
    department: 'sales'
  }
]
```

### 흐름 해설

1. `printEmployees` 호출
2. `async` 함수 안에서 `await`을 만나면, **기다리는 동안 함수 밖으로 빠져나와** 아래 코드(**Task 2, Task 3**)를 **먼저 실행**
3. **Promise가 Fulfilled**가 되면, 다시 함수 본문으로 돌아와 **이어서 실행**
4. 최종적으로 **데이터가 나중에 출력**됨

> 핵심: **`async` 함수 + `await`** 을 쓰면, **대기 동안 바깥 코드가 계속 진행**되어 비동기 목적(대기 중 다른 일 처리)에 맞는 흐름을 만들 수 있습니다.

---

## 핵심 요약

- `await`은 **`async` 함수 내부** 또는 **ES 모듈 최상위**에서만 사용합니다.
- 최상위 `await`은 그 줄에서 **대기 → 아래 줄이 나중에 실행**됩니다.
- `async` 함수로 감싸면, **대기 동안 함수 밖 코드가 먼저 진행**됩니다.
- `await`은 **Promise 완료까지 기다렸다가 결괏값을 반환**합니다.
- 이 흐름을 이해하면 **Promise 기반 비동기 코드**를 자연스럽게 작성할 수 있습니다.
