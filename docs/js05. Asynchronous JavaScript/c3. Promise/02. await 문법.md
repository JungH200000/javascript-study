# await 문법

**정의(한 줄 요약)**

- **`await`**: **Promise가 결과를 가질 때까지 기다렸다가 그 결괏값을 돌려주는 키워드**.

---

## 1) `fetch`의 반환값과 `await`

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
console.log(response);
```

- `fetch(...)`는 **Promise**를 반환합니다.
- `await`을 붙이면 **비동기 작업이 끝날 때까지 대기**한 뒤, **완료 결과(여기서는 `Response` 객체)** 가 `response`에 담깁니다.

실행 예:

```terminal
Response {
  status: 200,
  statusText: 'OK',
  headers: Headers { ... },
  body: ReadableStream { ... },
  bodyUsed: false,
  ok: true,
  redirected: false,
  type: 'basic',
  url: 'https://learn.codeit.kr/api/employees'
}
```

---

## 2) 응답 본문 파싱: `response.json()`

응답을 **사용하기 쉬운 데이터**로 바꾸려면 JSON 파싱이 필요합니다.

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
const data = response.json();
console.log(data);
```

- 위처럼 쓰면 `json()`이 **또 다른 Promise를 반환**하기 때문에 **`Promise { <pending> }`** 가 보입니다.

따라서 다음과 같이 **파싱도 기다려야** 합니다.

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
const data = await response.json();
console.log(data);
```

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
console.log(await response.json());
```

## 3) `await`이 작동하는 원리

아래 코드로 흐름을 설명합니다.

```js
const response = await fetch('https://learn.codeit.kr/api/employees');
const data = await response.json();

console.log(data);
```

### Promise의 3가지 상태

1. **Pending**: 비동기 작업 **진행 중**
2. **Fulfilled**: 비동기 작업 **성공**
3. **Rejected**: 비동기 작업 **실패**

### 흐름

- 처음 `fetch(...)`의 Promise는 **Pending**입니다.
- `await`은 **Fulfilled 또는 Rejected가 될 때까지 대기**합니다. (현재는 **성공 흐름**에 집중)
- 성공하면 **결괏값(`Response`)을 반환**하고, 이것이 `response` 변수에 **할당**됩니다.
- `response.json()`도 **Promise**를 반환하므로 다시 `await`으로 **파싱 완료**를 기다렸다가, **파싱된 데이터**가 `data`에 **할당**됩니다.
- 최종적으로 `console.log(data)`에서 **직원 데이터가 출력**됩니다.

> 핵심: **Promise를 반환하는 표현식 앞에 `await`을 붙이면, 작업이 성공(Fulfilled)할 때까지 기다렸다가 그 **결괏값을 돌려**받는다.**

---

## 핵심 요약

- `fetch`는 **Promise**를 반환하고, **`await`** 으로 **완료 결과**를 받을 수 있습니다.
- `response.json()` 역시 **Promise**이므로 **한 번 더 `await`** 해야 실제 데이터가 나옵니다.
- **Promise 상태**는 Pending → (성공) Fulfilled / (실패) Rejected이며, 현재는 **성공 흐름** 기준으로 설명합니다.
- **기억 포인트**: **Promise를 반환하는 표현식 앞엔 `await`**—결괏값을 **그 자리에서** 받을 수 있습니다.
