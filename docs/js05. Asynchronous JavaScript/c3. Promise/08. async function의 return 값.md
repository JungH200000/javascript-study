# async 함수의 return 값

**정의(한 줄 요약)**

- **async 함수**는 **항상 `Promise`를 반환**하며, 함수 내부에서 `await`은 **해당 `Promise`가 결과를 가질 때까지 기다린 뒤 그 결괏값을 돌려줍니다.**

---

## 1) async 함수는 항상 Promise를 반환한다

```js
export async function getEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees');
  const data = await response.json();

  return data;
}
```

**해설**

- `fetch(...)`와 `response.json()`은 **시간이 걸릴 수 있는 비동기 작업**입니다.
- `await`은 각 작업의 **성공 결과**를 받아 `response`, `data`에 **순서대로 할당**합니다.
- `return data;`를 하더라도, **async 함수의 반환값은 항상 `Promise`** 입니다. (내부에서 값을 반환해도 바깥에는 `Promise(그 값)` 형태로 전달됨)

---

## 2) 바깥에서 보면 왜 `Promise { <pending> }`일까?

```js
import { getEmployees } from './asyncFunctions.js';

const employees = getEmployees(); // ← 여기서 '즉시' 돌아오는 건 Promise
console.log(employees);
```

```terminal
Promise { <pending> }
```

**핵심 포인트**

- `getEmployees()`는 **곧바로 `Promise`** 를 돌려줍니다.
- 내부 `fetch`/`json()`이 **아직 끝나지 않았기 때문에** 콘솔에는 **`<pending>`(대기 중)** 으로 보입니다.

---

## 3) 실제 데이터가 필요하면 앞에 `await`을 붙인다

```js
import { getEmployees } from './asyncFunctions.js';

const employees = await getEmployees(); // ← Fulfilled가 될 때까지 기다림
console.log(employees);
```

**해설**

- `await getEmployees()`는 `getEmployees()`가 반환한 `Promise`가 **Fulfilled**가 될 때까지 **대기**하고,
  그 **결괏값(직원 배열)** 을 `employees`에 **직접 할당**합니다.

실행 예:

```terminal
[
  { id: 1, name: 'Jason', email: 'jason@codeitmall.kr', department: 'engineering' },
  ...
  { id: 10, name: 'Alex',  email: 'alex@codeitmall.kr',  department: 'sales' }
]
```

원하는 요소만 바로 사용할 수도 있습니다.

```js
import { getEmployees } from './asyncFunctions.js';

const employees = await getEmployees();
const employee = employees[0];
console.log(employee);
```

```terminal
{
  id: 1,
  name: 'Jason',
  email: 'jason@codeitmall.kr',
  department: 'engineering'
}
```

---

## 4) async 함수가 **다른 Promise를 그대로 반환**하는 형태

```js
export async function getEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees');
  return response.json(); // ← 이 Promise의 상태/결과를 그대로 따름
}
```

**해설**

- 위처럼 **다른 `Promise`를 그대로 `return`** 하면, `getEmployees()`가 돌려주는 `Promise`는
  `response.json()`의 **상태/결과**를 **그대로 따릅니다**(성공 시 파싱된 데이터).

바깥 사용은 동일합니다.

```js
import { getEmployees } from './asyncFunctions.js';

const employees = await getEmployees();
const employee = employees[0];
console.log(employee);
```

---

## 5) (권장) 어떤 것을 `await`하는지 **한눈에 보이게** 작성

```js
export async function getEmployees() {
  const response = await fetch('https://learn.codeit.kr/api/employees');
  const data = await response.json(); // ← 어떤 비동기 작업을 기다리는지 명확

  return data;
}
```

**포인트**

- 각 단계에서 **기다리는 작업이 명확**해져 흐름을 이해하기 쉽습니다.
- 반환값은 여전히 **`Promise(데이터)`** 입니다(바깥에서는 `await`로 받아 사용).
