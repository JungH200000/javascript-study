# `typeof` 연산자

> **정의 한 줄 요약**: `typeof`는 **값의 데이터 타입 이름을 문자열로 반환**하는 단항 연산자다. (예: `typeof 10` → `'number'`)
> **사용 형태**: `typeof 값` 또는 `typeof(값)` 두 방식 모두 가능.

---

## 기본 예시

```javascript
console.log(typeof Symbol()); // symbol
console.log(typeof 10); // number
console.log(typeof 'ABC'); // string
console.log(typeof 31n); // bigint
console.log(typeof true); // boolean
console.log(typeof {}); // object
console.log(typeof []); // object
```

- 위 예시처럼 결과는 **문자열**이다.
- `{}`(객체 리터럴)과 `[]`(배열) 모두 `object`로 나오므로, `typeof` 결과가 **모든 타입과 1:1로 매칭되지는 않는다**는 점을 염두에 두자.

---

## 주의 1) `null`이 `object`라고?

```javascript
console.log(typeof null); // object
```

- `typeof null`은 `'null'`이 아니라 **`'object'`** 를 반환한다.
- 이는 JavaScript 초기 **문법 설계상의 이유**로 생긴 역사적 결과이며(수정 제안이 있었지만 광범위한 호환성 문제로 반영되지 않음), 자세한 배경은 아래 링크 참고.
  [https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Operators/typeof#null](https://developer.mozilla.org/ko/docs/Web/JavaScript/Reference/Operators/typeof#null)

---

## 주의 2) `function`?

```javascript
function hello() {
  console.log('Hi, hello!');
}

console.log(typeof hello); // function
```

- JavaScript에서 **함수는 객체로 취급**되지만, `typeof`를 함수에 적용하면 결과는 **`'function'`** 이다.
- 종종 `object`일 것이라 오해하기 쉬우므로 주의하자.

---

## 핵심 요약

- `typeof`는 값의 **타입 이름을 문자열**로 돌려준다.
- `{}`와 `[]`가 모두 `object`로 나오는 것처럼, **모든 타입이 1:1로 구분되지는 않는다**.
- **`typeof null === 'object'`** 는 언어 초창기 설계에 따른 결과다.
- **함수는 객체**이지만 `typeof` 결과는 **`'function'`** 이다.
