# AND와 OR의 연산 방식

> **정의 한 줄 요약**: JavaScript의 논리 연산자 `&&`/`||`는 상황에 따라 **불린을 반환하지 않고 피연산자 중 하나를 그대로 반환**한다.
>
> - `A && B`: **왼쪽이 Truthy면 `B`**, **왼쪽이 Falsy면 `A`**
> - `A || B`: **왼쪽이 Truthy면 `A`**, **왼쪽이 Falsy면 `B`**

---

## 1) 왜 `'JavaScript'`가 찍힐까?

```js
console.log('hello' && 'JavaScript'); // JavaScript
```

- 둘 다 **Truthy**인데도 `true`가 아니라 **오른쪽 값**이 출력된다.
- 이유: `&&`는 **왼쪽이 Truthy → 오른쪽을 반환**, **왼쪽이 Falsy → 왼쪽을 반환**하기 때문이다.

---

## 2) 불린 값으로 본 AND(&&) 기본

```js
console.log(true && true); // true
console.log(true && false); // false
console.log(false && true); // false
console.log(false && false); // false
```

- 불린만 놓고 보면 **둘 다 true일 때만 true**.
- 하지만 **일반 값**에선 위 규칙을 **값 선택** 형태로 이해하면 된다.

```js
console.log('hello' && 'JavaScript'); // 왼쪽 값이 Truthy → 오른쪽 값 반환
```

---

## 3) OR(||) 기본

```js
console.log(true || true); // true
console.log(true || false); // true
console.log(false || true); // true
console.log(false || false); // false
```

- 불린만 보면 **하나라도 true면 true**.
- **값 선택 관점**: `||`는 `&&`의 반대로 동작한다.

  - **왼쪽이 Truthy면 왼쪽 반환**, **왼쪽이 Falsy면 오른쪽 반환**

---

## 4) 불린이 아닌 값으로 연습

```js
console.log(null && undefined); // null         (왼쪽 Falsy → 왼쪽 반환)
console.log(0 || true); // true         (왼쪽 Falsy → 오른쪽 반환)
console.log('0' && NaN); // NaN          (왼쪽 Truthy → 오른쪽 반환)
console.log({} || 123); // {}           (왼쪽 Truthy → 왼쪽 반환)
```

---

## 5) 간단한 응용: 기본값 선택

```js
function prints(value) {
  const message = value || 'Hello';
  console.log(message);
}

prints(); // value = undefined → 'Hello'
prints('JavaScript'); // 'JavaScript'
```

- `value`가 **Falsy**면 오른쪽 `'Hello'`를 사용하고, **Truthy**면 왼쪽 `value`를 그대로 사용한다.

---

## 한눈에 정리 (동작 규칙 표)

| 연산자     | 왼쪽이 Truthy일 때 | 왼쪽이 Falsy일 때 |
| ---------- | ------------------ | ----------------- |
| `A && B`   | `B` 반환           | `A` 반환          |
| `A \|\| B` | `A` 반환           | `B` 반환          |

---

## 핵심 요약

- `&&`/`||`는 **불린만 반환하는 게 아니라** 피연산자 **값 자체**를 선택해 반환한다.
- `&&`: **왼쪽 Truthy → 오른쪽**, **왼쪽 Falsy → 왼쪽**.
- `||`: **왼쪽 Truthy → 왼쪽**, **왼쪽 Falsy → 오른쪽**.
- 이 규칙으로 **Truthy/Falsy**를 활용해 **기본값**을 간단히 설정할 수 있다.
