# Parameter (파라미터)

> **정의 한 줄 요약**: **파라미터(Parameter)** 는 _함수 선언의_ `()` 안에서 **받을 값을 가리키는 변수**, **아규먼트(Argument)** 는 _함수 호출 시_ **실제로 전달하는 값**이다.

---

## 파라미터와 아규먼트 구분

```js
function greeting(name) {
  console.log(`My name is ${name}`);
}
```

- `name` → **파라미터**(함수 선언부의 자리표시자).
- 아래처럼 **아규먼트**가 달라지면 같은 함수도 다른 결과가 나온다.

```js
greeting('JavaScript'); // My name is JavaScript
greeting('Chung'); // My name is Chung
greeting('World'); // My name is World
```

---

## 파라미터 기본값

- 아규먼트 없이 호출하면 파라미터는 기본적으로 **`undefined`** 를 가진다.

```js
function greeting(name) {
  console.log(`My name is ${name}`);
}

greeting(); // name === undefined
```

- **기본값**을 지정하면, 아규먼트를 생략했을 때 그 값을 사용한다.

```js
function greeting(name = 'Chung') {
  console.log(`My name is ${name}`);
}

greeting(); // My name is Chung
```

---

## 여러 파라미터와 기본값의 위치

- 아규먼트는 **작성한 순서대로** 파라미터에 전달된다.
- 기본값이 필요한 파라미터는 **가급적 오른쪽**에 두는 것이 안전하다.

```js
function greeting(name = 'Chung', interest) {
  console.log(`My name is ${name}`);
  console.log(`I like ${interest}`);
}

greeting('JavaScript');
// My name is JavaScript
// I like undefined
```

---

## 기본값이 적용되는 조건: `undefined`

- **아규먼트가 생략되거나 `undefined`로 전달**되면 기본값이 적용된다.

```js
function greeting(name = 'Chung', interest = 'JavaScript') {
  console.log(`My name is ${name}`);
  console.log(`I like ${interest}`);
}

greeting('Java');
// My name is Java
// I like JavaScript

greeting(undefined, 'C++');
// My name is Chung
// I like C++
```

> 참고: **`null`은 그대로 전달**되므로 기본값으로 바뀌지 않는다.

---

## 앞선 파라미터를 이용한 기본값

- 뒤 파라미터의 기본값에서 **앞서 정의된 파라미터를 참조**할 수 있다.

```js
function defaultTest(x, y = x + 3) {
  console.log(`x: ${x}`);
  console.log(`y: ${y}`);
}

defaultTest(2);
// x: 2
// y: 5
```

- 두 번째 아규먼트를 주면 **그 값을 그대로 사용**한다.

```js
defaultTest(2, 4);
// x: 2
// y: 4
```

---

## 문법 지원 범위

- **파라미터 기본값 문법은 ES2015 도입**.
  ES2015 이후 문법을 지원하지 않는 환경에서는 사용할 수 없다.

---

## 핵심 요약

- **파라미터**: 선언부의 자리표시자 / **아규먼트**: 호출 시 전달하는 실제 값.
- 아규먼트를 생략하면 파라미터는 **`undefined`**, **기본값**이 있으면 그 값을 사용.
- 기본값은 **`undefined`가 전달될 때만** 적용(`null`은 그대로 전달).
- 기본값은 **앞 파라미터를 참조**할 수 있으며, **오른쪽에 두는 것**이 안전하다.
- 이 문법은 **ES2015**부터 지원된다.
