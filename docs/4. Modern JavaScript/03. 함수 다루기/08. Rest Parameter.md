# Rest Parameter

> **정의 한 줄 요약**: **Rest Parameter**는 파라미터 이름 앞에 `...`를 붙여 **나머지 아규먼트들을 배열로 수집**하는 문법이다(ES2015).

---

## 왜 Rest Parameter인가?

`arguments` 객체로도 가변 길이 아규먼트를 다룰 수 있지만 한계가 있다.

- **유사 배열**이라 배열 메서드 사용 불가
- **항상 전체 아규먼트**를 담으므로, 일부분만 다루려면 **인덱싱으로 추가 작업** 필요

Rest Parameter는 이 두 문제를 **배열 형태로 해결**해 준다.

---

## `arguments` 사용 예 (이용 전)

```js
function printArgument(a, b, c) {
  // 전달된 모든 아규먼트를 순회
  for (const arg of arguments) {
    console.log(arg);
  }
  console.log('--------------');
}

printArgument('JavaScript');
printArgument('Jav', 'Hyun', 'Chung', 'Lee');
printArgument('Ha', 'Ah');
```

- `arguments`는 **유사 배열**이어서 값은 담지만, 배열 메서드는 쓸 수 없다.

---

## Rest Parameter 사용 예 (이용 후)

```js
function printArgument(...args) {
  // 나머지 아규먼트를 '배열'로 수집
  for (const arg of args) {
    console.log(arg);
  }
  console.log('--------------');
}

printArgument('JavaScript');
printArgument('Jav', 'Hyun', 'Chung', 'Lee');
printArgument('Ha', 'Ah');
```

- `...args`는 **진짜 배열**이므로 배열 메서드를 바로 사용할 수 있다.

---

## 배열 메서드 사용 가능 여부 비교

```js
function printArgument(...args) {
  console.log(args.splice(0, 2)); // 배열 메서드 OK → 앞에서 두 개를 잘라 반환
  console.log(arguments.splice(0, 2)); // TypeError: arguments.splice is not a function
  console.log('--------------');
}

printArgument('JavaScript');
printArgument('Jav', 'Hyun', 'Chung', 'Lee');
printArgument('Ha', 'Ah');
```

- `args.splice(...)` ✅: `args`는 배열
- `arguments.splice(...)` ❌: `arguments`는 유사 배열(배열 메서드 없음)

---

## 일반 파라미터와 함께 쓰기

```js
function printRank(first, second, ...others) {
  console.log('경시대회 최종 결과');
  console.log(`대상: ${first}`); // 첫 번째 아규먼트
  console.log(`금상: ${second}`); // 두 번째 아규먼트
  // 나머지 아규먼트는 배열로
  for (const other of others) {
    console.log(`참가자: ${other}`);
  }
}

printRank('Chung', 'Ji', 'Hyun', 'Jung', 'Hak');
```

- Rest Parameter는 **앞에 정의된 파라미터에 값을 먼저 할당한 뒤**, **나머지**를 배열로 모은다.
- 따라서 **항상 마지막에** 작성해야 한다.

---

## 마무리 코멘트

- 대부분의 상황에서는 **Rest Parameter**가 더 간결하고 유연하다.
- 다만 환경/상황에 따라 `arguments`를 써야 할 때도 있으므로 **두 방식의 차이**를 이해해 두자.
- (참고) Rest Parameter 문법은 **ES2015**에서 도입되었다.

---

## 핵심 요약

- `arguments`는 **유사 배열**(배열 메서드 X), Rest는 **진짜 배열**(메서드 O).
- Rest는 `...이름`으로 **나머지 아규먼트를 배열로 수집**한다.
- Rest는 **항상 마지막 파라미터**에만 올 수 있다.
- 가변 인자를 다룰 때는 **Rest를 우선**하고, 필요 시 `arguments`를 사용한다.
