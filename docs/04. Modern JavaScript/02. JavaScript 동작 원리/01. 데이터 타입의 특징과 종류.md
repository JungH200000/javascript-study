# 데이터 타입의 특징과 종류

> **정의 한 줄 요약**: JavaScript는 **값이 흘러가며 타입이 바뀔 수 있는 언어**로, 상황(연산·대입)에 따라 **값의 타입이 달리 해석**될 수 있다.

- **유연함의 의미**: 변수에 타입을 미리 고정하지 않으며, 연산 시 값이 **자동으로 다른 타입으로 해석**될 수 있다.
  예) `2 + '3'` → `'23'`(문자열 연결), `2 * '3'` → `6`(숫자 곱셈).
- **재할당 자유도**: 같은 변수에 서로 다른 타입의 값을 다시 넣을 수 있다(예상치 못한 결과를 막으려면, 현재 값이 **무슨 타입인지 인지**하고 써야 한다).

---

## 예시: 한 변수에 여러 타입을 재할당

```javascript
let x = 15; // 숫자(정수)

x = 'Hello'; // 문자열
x = true; // 불리언
x = null; // null
x = undefined; // undefined
x = {}; // 객체(참조형의 대표)
```

- `let x = 15;` → 숫자로 시작한다.
- 이후 줄들은 **같은 변수 `x`** 에 서로 다른 타입의 값을 **순차적으로 재할당**하는 예시다.
- 이처럼 **변수 자체는 타입이 고정되지 않는다**는 점이 JavaScript의 큰 특징이다.

---

## JavaScript의 데이터 타입 (총 8가지)

> **요약**: **기본형(7)** + **참조형(1)**

### 기본형(Primitive Type)

- **number, string, boolean, null, undefined, symbol(ES2015), bigint(ES2020)**

  - `symbol`: **서로 겹치지 않는 유일한 값**을 만들 때 사용.
  - `bigint`: **아주 큰 정수**를 안전하게 다룰 때 사용.
  - 두 타입(symbol/bigint)은 비교적 **특수한 상황**에서 주로 쓰인다.

### 참조형(Reference Type)

- **object**

> 실무에서 자주 마주치는 타입은 **number, string, boolean, null, undefined, object**다.
> (symbol, bigint는 필요할 때 선택적으로 사용)

---

## 왜 타입 이해가 중요한가

- JavaScript는 **연산 맥락에 따라 값의 타입이 달리 해석**되기도 한다(문자열 연결 vs 숫자 연산 등).
- 따라서 **내 코드가 어떤 타입의 값을 만들고 있는지**를 항상 의식하면 **예측 불가한 동작과 오류**를 줄일 수 있다.

---

## 핵심 요약

- JavaScript는 **변수에 타입을 고정하지 않는 언어**로, **값과 맥락**이 타입 해석을 좌우한다.
- **같은 변수**에 **서로 다른 타입**을 재할당할 수 있으며, **연산 중 자동 해석**(문자열 연결/숫자 연산)이 일어난다.
- 타입은 총 **8가지**: 기본형 7(number, string, boolean, null, undefined, symbol, bigint) + 참조형 1(object).
- **symbol/bigint**는 **특수 목적**에 가깝고, 일상적으로는 **number/string/boolean/null/undefined/object**을 주로 다룬다.
- **현재 값의 타입을 명확히 인지**하는 습관이 예기치 못한 버그를 줄인다.
