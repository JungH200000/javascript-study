# 즉시 실행 함수(IIFE)

> **정의 한 줄 요약**: **즉시 실행 함수(IIFE)** 는 **함수 “표현”을 정의하자마자 곧바로 호출**하는 문법이다. (Immediately Invoked Function Expression)

---

## 함수 선언과 실행은 다르다

```js
function sayHi() {
  console.log('Hi!');
}

sayHi();
```

- 위 코드는 **함수를 선언**한 뒤, **함수 이름 뒤의 `()`** 로 **실행**한다.

---

## 즉시 실행 함수

```js
(function () {
  console.log('Hi');
})(); // Hi
```

- **함수 표현식을 괄호로 감싸** 표현식으로 만든 뒤, **곧바로 `()` 로 호출**한다.
- 선언과 동시에 실행된다.

```js
(function (x, y) {
  console.log(x + y);
})(3, 5);
```

- IIFE도 일반 함수처럼 **파라미터/아규먼트**를 사용할 수 있다.

### 이름이 있어도 외부에선 재사용 불가

```js
(function sayHi() {
  console.log('Hi!');
})();

sayHi(); // ReferenceError: sayHi is not defined
```

- IIFE에 **이름을 붙여도 그 이름은 외부에서 보이지 않는다.**
- 다만, **함수 내부에서 자기 자신을 호출**하는 **재귀 구조**가 필요하다면 이름을 붙일 수 있다.

```js
(function countdown(n) {
  console.log(n);
  if (n === 0) {
    console.log('End!');
  } else {
    countdown(n - 1);
  }
})(5);
```

---

## 즉시 실행 함수의 활용

### 1) 프로그램 초기화 코드에 사용

```js
(function init() {
  // 프로그램이 실행 될 때 기본적으로 동작할 코드들..
})();
```

### 2) 일회성 동작의 결과를 바로 변수에 담기

```js
const firstName = 'Young';
const lastName = 'Kang';

const greetingMessage = (function () {
  const fullName = `${firstName} ${lastName} `;

  return `Hi! My name is ${fullName}`;
})();
```

- IIFE의 **반환값을 즉시 변수에 할당**할 수 있다.
- IIFE 내부에서 사용하는 변수들은 **함수 내부에서만 유효**하므로, **일시적 이름을 자유롭게** 사용할 수 있다.

---

## 핵심 요약

- IIFE는 **함수 표현식을 즉시 호출**하는 패턴이다.
- **괄호로 감싼 함수 표현식 + 즉시 호출 `()`** 형태로 작성한다.
- IIFE 이름은 **외부에서 재사용할 수 없지만**, **내부 재귀 호출**에는 사용할 수 있다.
- **초기화/일회성 계산** 등에 유용하며, **내부 변수는 지역적**으로만 유효하다.
