# Named Function Expression (기명 함수 표현식)

> **정의 한 줄 요약**: **기명 함수 표현식**은 *함수 표현식*에 **이름을 붙인 형태**로, 함수 내부에서 **자기 자신을 안정적으로 참조**할 수 있게 해 준다(재귀 등).

---

## 1) 함수 이름과 `name` 프로퍼티

```js
const sayHi = function () {
  console.log('Hi');
};

console.log(sayHi.name); // sayHi
```

- **익명 함수**를 변수에 할당하면, 변수의 이름이 **`name` 프로퍼티 값**으로 잡힌다.

```js
const sayHi = function printHiConsole() {
  console.log('Hi');
};

console.log(sayHi.name); // printHiConsole
```

- **기명 함수 표현식**을 쓰면, `name`은 **함수에 붙인 이름**이 된다.

---

## 2) 함수 이름의 가시성(스코프)

```js
const sayHi = function printHiConsole() {
  console.log('Hi');
};

printHiConsole(); // ReferenceError: printHiConsole is not defined
```

- 붙인 **함수 이름은 함수 내부에서만** 유효하다. 외부에서는 **그 이름으로 호출 불가**.

---

## 3) 익명 함수 표현식 + 재귀에서 생길 수 있는 문제

```js
let countdown = function (n) {
  console.log(n);

  if (n === 0) {
    console.log('End!');
  } else {
    countdown(n - 1); // 바깥 변수 이름에 의존
  }
};

countdown(5);
```

- 위 코드는 동작하지만, **바깥 변수**가 바뀌면 문제가 생긴다:

```js
let countdown = function (n) {
  console.log(n);

  if (n === 0) {
    console.log('End!');
  } else {
    countdown(n - 1); // 여기서 countdown이 바뀌면 재귀가 끊긴다
  }
};

let myFunction = countdown;
countdown = null;

myFunction(5); // TypeError: countdown is not a function
```

- `countdown = null`로 **외부 참조가 바뀌어** 재귀 호출 지점에서 **에러** 발생.

---

## 4) 기명 함수 표현식으로 해결(자기 참조 고정)

```js
let countdown = function printCountdown(n) {
  console.log(n);

  if (n === 0) {
    console.log('End!');
  } else {
    printCountdown(n - 1); // 함수 내부의 이름으로 자기 자신 호출 (안정적)
  }
};

let myFunction = countdown;

countdown = null;

myFunction(5); // 정상 동작
```

- 내부 이름 `printCountdown`은 **함수 본문 안에서만** 보이며, 외부 변수 재할당과 **무관하게 유지**된다.
- 따라서 외부에서 변수를 바꿔도 **재귀가 안전**하게 동작한다.

> 정리 문장: `let`/`const` 변수는 **재할당될 수 있으므로**, 함수 내부에서 자기 자신을 써야 한다면 **기명 함수 표현식으로 내부 이름을 사용**하는 것이 안전하다.

---

## 핵심 요약

- **기명 함수 표현식**: 함수 표현식에 이름을 붙여 **내부에서 자기 자신을 참조**할 수 있게 함.
- 익명 표현식은 **외부 변수 이름에 의존**하므로, 그 변수가 바뀌면 **재귀가 깨질 수 있음**.
- 기명 함수 표현식은 **외부 재할당과 무관**하게 **안정적인 자기 참조**를 제공한다.
- 함수 외부에서는 붙인 **내부 이름으로 호출할 수 없다**(내부에서만 유효).
